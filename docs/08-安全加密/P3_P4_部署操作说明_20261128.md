## 三、应急回滚

| 场景 | 操作 |
|---|---|
| 部署后功能异常, 需回退代码 | 用步骤 1 留的 `.bak_p3p4` 原 jar 覆盖回去 → 重启(数据无损失, 密文兼容不受影响) |
| 06 号视图异常 | 重跑 `sqls/security/01_masked_views.sql` 恢复旧定义(密文列输出仍乱码, 仅定义还原) |
| P4-a 后异常 | 删除追加的两行 V1 键 → 重启 |
| 解密大量失败(110028) | 立即检查是否误改了 `encryptKey/encryptIv`(legacy 不可动)或 V1 值配错; 改回 844dd1 组重启 |
