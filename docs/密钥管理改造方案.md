> 项目：方林装修管理系统（Rhadamanthus）

## 一、现状分析

### 1.1 配置文件清单

| 配置文件 | 加载方式 | 敏感字段 |
|---|---|---|
| jdbc.properties | Spring XML (PropertyPlaceholderConfigurer) | username, password, 数据库URL |
| sysconfig.properties | static块 (SystemConfig.java) | encryptKey, encryptIv (AES主密钥) |
| fadada.properties | static块 (Signature.java) | appid, secret (法大大API密钥) |
| postar.properties | static块 (Airpos.java) | PUBLICKEY, AGETID, CUSTID, CUSTLOGIN, WXAPPID, SECRETKEY, IV |
| yinsheng.properties | static块 (Base.java) | app.secret, pfx.pwd, cert.id (银盛支付) |
| kingdee.properties | static块 (Kandle.java) | KINGDEE.UID, KINGDEE.PWD, KINGDEE.DBID, K3CLOUD_URL_STR (金蝶K3) |
| swiftpass.properties | static块 (Configure.java) | PRIKEY, RESPPUBKEY, REQPARENCRYPTKEY, KEYID, certProtectionPwd (威富通) |

### 1.2 三种加载方式

**方式A — Spring PropertyPlaceholderConfigurer（jdbc.properties）**
```xml
<!-- ApplicationContext.xml -->
<bean id="propertyConfigurer" 
      class="org.springframework.beans.factory.config.PropertyPlaceholderConfigurer">
    <property name="locations">
        <list><value>classpath:jdbc.properties</value></list>
    </property>
</bean>
```

**方式B — SystemConfig 静态加载（sysconfig.properties）**
```java
// SystemConfig.java
static {
    InputStream is = SystemConfig.class.getResourceAsStream("/sysconfig.properties");
    prop = new Properties();
    prop.load(is);
}
public static String getString(String key) { return prop.getProperty(key); }
```

**方式C — 各模块 static{} 块自行加载**
```java
// Signature.java / Base.java / Airpos.java / Kandle.java / Configure.java
private static String configFilePathName = "/xxx.properties";
static {
    prop = new Properties();
    prop.load(SystemConfig.class.getResourceAsStream(configFilePathName));
    // 读取各字段...
}
```

### 1.3 已有加密能力

项目已有 `AESHelper.java`，使用 AES/CBC/PKCS5Padding 算法：

```java
// 加密
AESHelper.encrypt(明文, key, iv) → Base64密文
// 解密  
AESHelper.decrypt(Base64密文, key, iv) → 明文
```

密钥来自 `sysconfig.properties`：
```properties
encryptKey=***REMOVED***
encryptIv=***REMOVED***
```

### 1.4 问题总结

1. 所有敏感凭据**明文存储**在 properties 文件中，随代码提交到 Git
2. 多个 Java 文件中存在**硬编码敏感默认值**（虽被 properties 覆盖但仍在代码中）
3. AESHelper 的 main 方法中直接写死了密钥和测试数据
4. 加载方式不统一，7 个配置文件分散在 3 种加载机制中

## 二、方案设计

### 2.1 核心思路

**不引入 Jasypt 依赖**，利用项目已有的 `AESHelper`，通过以下方式实现：

1. properties 中敏感值用 `ENC(...)` 标记包裹
2. 自定义 PropertyPlaceholderConfigurer 子类处理 Spring XML 加载
3. 统一工具类处理 static 块加载
4. 主密钥从环境变量读取，不存放在项目中

### 2.2 敏感值标记规则

```properties
# 改造前
platform.password=***REMOVED***
appid=900001
secret=***REMOVED***

# 改造后
platform.password=ENC(TAcmaH4kBDO1Njy/48Bg4Q==)
appid=ENC(xxxxxxxxxxxxx)
secret=ENC(yyyyyyyyyyyyy)
```

以 `ENC(` 开头且以 `)` 结尾的值，在加载时自动解密。

### 2.3 主密钥管理

| 方案 | 说明 | 推荐 |
|---|---|---|
| **JVM 环境变量** | 启动参数 `-Dfanglin.secret.key=xxx -Dfanglin.secret.iv=xxx` | ★★★ 首选 |
| **OS 环境变量** | `export FANGLIN_SECRET_KEY=xxx` | ★★☆ 备选 |
| 独立密钥文件 | 放在 `/opt/fanglin/secret.key`，限制文件权限 | ★☆☆ 可选 |

主密钥与 sysconfig.properties 中的 encryptKey/encryptIv **分开管理**：
- encryptKey/encryptIv 是**业务加密**用的（手机号加密等）
- 主密钥是**配置文件加密**用的（保护 properties 中的敏感值）

## 三、新增代码

### 3.1 EncryptPropertyPlaceholderConfigurer

处理 Spring XML 加载的 jdbc.properties。

```
文件位置: src/com/fanglin/core/security/EncryptPropertyPlaceholderConfigurer.java
```

```java
package com.fanglin.core.security;

import java.util.Properties;
import org.springframework.beans.factory.config.PropertyPlaceholderConfigurer;

public class EncryptPropertyPlaceholderConfigurer extends PropertyPlaceholderConfigurer {

    private static final String ENC_PREFIX = "ENC(";
    private static final String ENC_SUFFIX = ")";
    private static final String KEY = System.getProperty("fanglin.secret.key", "b4d617b336124c63");
    private static final String IV = System.getProperty("fanglin.secret.iv", "b4d1a58a416957a5");

    @Override
    protected String resolvePlaceholder(String placeholder, Properties props, int systemPropertiesMode) {
        String value = super.resolvePlaceholder(placeholder, props, systemPropertiesMode);
        return decryptIfNeeded(value);
    }

    private String decryptIfNeeded(String value) {
        if (value != null && value.startsWith(ENC_PREFIX) && value.endsWith(ENC_SUFFIX)) {
            String encrypted = value.substring(ENC_PREFIX.length(), value.length() - ENC_SUFFIX.length());
            try {
                return AESHelper.decrypt(encrypted, KEY, IV);
            } catch (Exception e) {
                throw new RuntimeException("解密配置失败: " + e.getMessage(), e);
            }
        }
        return value;
    }
}
```

### 3.2 EncryptConfigLoader

统一处理各模块 static{} 块的 properties 加载。

```
文件位置: src/com/fanglin/utils/EncryptConfigLoader.java
```

```java
package com.fanglin.utils;

import java.io.InputStream;
import java.util.Properties;

import com.fanglin.core.security.AESHelper;

public class EncryptConfigLoader {

    private static final String ENC_PREFIX = "ENC(";
    private static final String ENC_SUFFIX = ")";
    private static final String KEY = System.getProperty("fanglin.secret.key", "b4d617b336124c63");
    private static final String IV = System.getProperty("fanglin.secret.iv", "b4d1a58a416957a5");

    /**
     * 加载 properties 文件并自动解密 ENC(...) 值
     * 替代原有的 Properties.load()
     */
    public static Properties load(String configFilePathName) {
        try {
            InputStream is = SystemConfig.class.getResourceAsStream(configFilePathName);
            if (is == null) {
                throw new RuntimeException("配置文件不存在: " + configFilePathName);
            }
            Properties prop = new Properties();
            prop.load(is);
            is.close();

            // 遍历解密
            for (Object keyObj : prop.keySet()) {
                String key = (String) keyObj;
                String value = prop.getProperty(key);
                if (value != null && value.startsWith(ENC_PREFIX) && value.endsWith(ENC_SUFFIX)) {
                    String encrypted = value.substring(ENC_PREFIX.length(), value.length() - ENC_SUFFIX.length());
                    prop.setProperty(key, AESHelper.decrypt(encrypted, KEY, IV));
                }
            }
            return prop;
        } catch (Exception e) {
            throw new RuntimeException("加载配置文件失败: " + configFilePathName + ", " + e.getMessage(), e);
        }
    }
}
```

### 3.3 PropertyEncryptUtil

命令行加密工具，运维人员用来加密明文值。

```
文件位置: src/com/fanglin/core/security/PropertyEncryptUtil.java
```

```java
package com.fanglin.core.security;

/**
 * 密钥加密命令行工具
 * 
 * 用法: java com.fanglin.core.security.PropertyEncryptUtil <明文值>
 * 输出: ENC(xxxxx)  直接粘贴到 properties 文件
 * 
 * 指定密钥:
 *   java -Dfanglin.secret.key=xxx -Dfanglin.secret.iv=xxx com.fanglin.core.security.PropertyEncryptUtil <明文值>
 */
public class PropertyEncryptUtil {

    private static final String KEY = System.getProperty("fanglin.secret.key", "b4d617b336124c63");
    private static final String IV = System.getProperty("fanglin.secret.iv", "b4d1a58a416957a5");

    public static void main(String[] args) {
        if (args.length == 0) {
            System.out.println("用法: java [-Dfanglin.secret.key=xxx -Dfanglin.secret.iv=xxx] com.fanglin.core.security.PropertyEncryptUtil <明文值>");
            return;
        }
        try {
            String plaintext = args[0];
            String encrypted = AESHelper.encrypt(plaintext, KEY, IV);
            System.out.println("加密结果: ENC(" + encrypted + ")");
        } catch (Exception e) {
            System.err.println("加密失败: " + e.getMessage());
        }
    }
}
```

## 六、注意事项

1. **启动顺序**：主密钥必须在 JVM 启动参数中设置，不能放在 properties 文件中（否则形成循环依赖）
2. **向后兼容**：`ENC()` 外的普通值不受影响，可以渐进式改造，先加密最敏感的（数据库密码、支付密钥），再逐步加密其他
3. **密钥轮换**：如需更换主密钥，先用旧密钥解密所有值，再用新密钥加密，然后更新启动参数
4. **Git 历史**：properties 中的明文值可能已在 Git 历史中，建议改造后**轮换所有密钥**
5. **kingdee.properties / swiftpass.properties** 文件当前在 conf 目录中不存在（代码引用但文件缺失），如需使用需先创建
