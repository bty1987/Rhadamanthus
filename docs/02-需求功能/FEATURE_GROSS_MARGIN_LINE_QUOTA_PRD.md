## 一、一句话定位

把毛利率从"月底财务口径"变成实时经营额度:集团/分公司发布毛利率管理线(年/季/月),每笔签单按"签单额×(实际毛利率−线)"计算让利额度,超线攒额度、低线耗额度,管理层看排名与缺口,谈单时按额度打折。

## 二、功能需求

### F1 毛利率看板(走老系统报表平台 metric_*)

- 三口径:**基装毛利率**(基装利润÷基装结算)、**主材毛利率**(主材利润÷主材结算)、**综合毛利率**((基装+全案+主材利润)÷(基装+全案+主材结算+设计业绩));
- 周期卡(年/季/月):实际毛利率 × 集团管理线/集团要求线/分公司线 + 达标公司数/公司总数;
- 按日趋势:当日累计实际毛利率 + 集团线 + 分公司线(阶梯);
- 公司排名榜/员工排名榜:实际毛利率、线值、缺口金额=(实际−线)×结算金额、正/负/净影响额、达标状态与预警文案;
- **计算铁律(写进报表平台取数规范)**:任何时间窗/组织维度一律**先汇总分子分母再相除,禁止对比率求平均**;分母为 0 显示"不可计算",禁止显示 0%;百分比两位小数,金额万元两位小数。

### F2 管理线配置与版本化发布(新表+新页面)

- 两类线:集团管理线 / 分公司要求线(要求线直接配置,不由实际数据反算);
- 周期三档:年(1 条)/季(4)/月(12);
- **发布即版本**,三张表:
  1. 版次表(公司/年份/线类型/操作人/时间);
  2. 变更明细表(周期×口径,before→after→change);
  3. 生效快照表(周期×公司 × {集团线,分公司线} × {综合/基装/主材}三口径 + 发布时实际值快照 + 数据时点);
- 历史不回改:线发布后实际数据变化不影响已发布线,报表可复现"当时按什么线考核";
- 配套页面:配置进度(每公司 已配/部分/未配周期数)、发布记录、版本修改详情。

### F3 订单额度明细(贡献/消耗)

```
基装利润 = 净业绩 − (未直采+直采+交通费−净利) × 发包价率(公司级参数)
工程毛利率(单) = (基装利润+全案利润) ÷ (基装收入+全案收入) × 100
  · 公司未配发包价率 → 该单不可计算(计缺配置数,页面提示补配置)
  · 收入合计为 0 → 0
订单额度(万元) = 签单额 × (工程毛利率 − 该公司当月综合管理线) ÷100 ÷10000
净额度 >0 贡献 / <0 消耗 / =0 不分类;公司当月无线 → 不入额度(显式提示,不按 0 线)
```

- 明细页:单号/签约公司/部门/设计师/签约日 + 签单额、管理线、工程毛利率、毛利率差、额度、贡献/消耗;类型筛选+分页;
- 汇总卡:年/季/月 ×(综合/工程/主材)额度 + 贡献/消耗分列;
- 剔除重签单。

### F4 兑现预估

```
单均额度 = 近 6 个月月度净额度平均 ÷ 同期订单总数
本月可支持单量 = 本月净额度 ÷ 单均额度(综合/工程两口径)
```

含义:超线额度=可让利预算,回答"本月攒的额度按历史单均还能给多少单打折"。

## 三、数据需求(老系统侧输入字段清单)

> ⚠️ 本节是**数据契约**不是表映射——下列字段在老系统库中的实际落表(装修单/结算/业绩相关表)由实施阶段核对填写,不臆造表名。

| 类别 | 需要的字段 | 用途 |
|---|---|---|
| 订单 | 单号、签单公司、签约时间、签单额、订单类型(基装/整装)、状态(识别重签)、部门、设计师 | 订单归集与过滤 |
| 业绩利润 | 净业绩、全案利润、基装收入、全案收入、未直采、直采、交通费、净利 | 基装利润与工程毛利率 |
| 主材 | 主材利润、主材结算金额 | 主材口径 |
| 设计 | 设计业绩 | 综合口径分母 |
| 公司参数 | 发包价率(按公司) | 基装利润扣减;建议做成公司级字典/配置,业务调参不改代码 |

实施前置:逐字段核对老系统落表并在本文补"字段映射表";对不存在的字段(如某项费用未落库)明确"待业务确认",不造数。

## 四、权限与多公司

- 看数据:集团看全部公司、分公司看同城/下属、部门/员工看自身(沿用老系统 functionright 功能点+数据权限既有机制);
- 管理线发布:集团线与分公司要求线各配独立功能点,发布必须留操作人与时间;
- 全链路带公司维度,禁止跨公司错配管理线(fl-yy 已踩过的坑:每单必须按签单公司匹配该公司当月线)。

## 五、交付物

1. 三张管理线表 + 发包价率配置的 SQL 脚本(按 `docs/09-SQL脚本` 规范留存,含验证与回退);
2. 报表平台新增 metric 配置(看板/趋势/排名);
3. 额度明细与兑现预估页面(新功能点,挂菜单);
4. 口径说明页内嵌("每个数字可点开看口径")。

## 六、验收标准

1. 同一公司同一月份,本模块综合毛利率与 fl-yy 看板差异 ≤0.5%(超出即对账定责);
2. 分母为 0 / 缺发包价率 / 无管理线 三种不可计算态全部显式呈现,无一处假 0;
3. 任一历史月份报表可按当期已发布线复现(版本快照有效);
4. 重签单不进额度;跨公司线不串;
5. 先汇总后相除铁律抽测:任取一部门,手工 SUM 分子分母相除与页面一致(不得等于该部门下员工毛利率的均值)。
