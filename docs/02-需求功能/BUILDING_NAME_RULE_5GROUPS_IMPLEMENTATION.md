> 更新时间：2025-01-01

## 📋 功能概述

实现了楼盘命名规则（BuildingNameRule）的完整管理功能，规则由**5组"输入"和"连接符"交替**组成。

### 核心特性
- ✅ 5个输入下拉框（数字字母/字母数字/数字/字母/空字符串）
- ✅ 5个连接符下拉框（-/#/门/门-/门#/座/座-/座#/甲/甲-/甲#/空字符串）
- ✅ 实时生成规则示例
- ✅ 规则以JSON格式存储
- ✅ 完整的CRUD功能

---

## 🎯 表单结构

### 输入字段（Input）
| 字段名 | 选项 |
|--------|------|
| 输入1-5 | 空字符串/数字字母/字母数字/数字/字母 |

**选项说明**：
- `空字符串` - ''
- `数字字母` - 'NUM_ALPHA' → 示例：1A
- `字母数字` - 'ALPHA_NUM' → 示例：A1
- `数字` - 'NUM' → 示例：1
- `字母` - 'ALPHA' → 示例：A

### 连接符字段（Separator）
| 字段名 | 选项 |
|--------|------|
| 连接符1-5 | 空字符串/-/#/门/门-/门#/座/座-/座#/甲/甲-/甲# |

**选项说明**：
| 值 | 显示文本 | 实际连接符 |
|----|---------|-----------|
| '' | 空字符串 | '' |
| '-' | '-' | '-' |
| '#' | '/' | '/' |
| 'MEN' | 门 | 门 |
| 'MEN-' | 门- | 门- |
| 'MEN#' | 门# | 门# |
| 'ZUO' | 座 | 座 |
| 'ZUO-' | 座- | 座- |
| 'ZUO#' | 座# | 座# |
| 'JIA' | 甲 | 甲 |
| 'JIA-' | 甲- | 甲- |
| 'JIA#' | 甲# | 甲# |

### 基础字段
- **规则编号** (buildingNameRuleId) - 必填，文本框
- **规则说明** (ruleContent) - 必填，文本框
- **规则示例** (ruleExample) - 自动生成，只读

## 🔄 数据流程

### 前端 → 后端（保存）
```
用户选择下拉框
    ↓
JS自动生成规则示例
    ↓
编码为JSON字符串
{
  "inputs": ["NUM_ALPHA", "", "NUM", "ALPHA", ""],
  "separators": ["-", "MEN", "ZUO", "JIA", ""]
}
    ↓
保存到 rule 字段
```

### 后端 → 前端（回显）
```
从数据库读取 rule 字段
    ↓
解析JSON字符串
    ↓
填充10个下拉框
    ↓
生成规则示例
```

### 规则示例生成逻辑
```
输入1: NUM_ALPHA → "1A"
连接符1: - → "-"
输入2: (空) → ""
连接符2: MEN → "门"
输入3: NUM → "1"
连接符3: ZUO → "座"
输入4: ALPHA → "A"
连接符4: - → "-"
输入5: (空) → ""
连接符5: (空) → ""

最终示例: "1A-门1座A-"
```

## 💾 数据存储

### JSON 格式
```json
{
  "inputs": [
    "NUM_ALPHA",
    "ALPHA_NUM",
    "NUM",
    "ALPHA",
    ""
  ],
  "separators": [
    "-",
    "MEN#",
    "ZUO-",
    "JIA",
    ""
  ]
}
```

### 数据库字段映射
| 数据字段 | 存储内容 | 示例 |
|---------|---------|------|
| buildingNameRuleId | 规则编号 | "RULE001" |
| rule | JSON字符串 | `{"inputs":[...],"separators":[...]}` |
| ruleExample | 自动生成的示例 | "1A-门#2座-3甲" |
| ruleContent | 规则说明 | "标准命名规则" |
| rulefill | 未使用 | - |

## 🎯 功能特点

### 1. 实时预览
- 用户选择输入/连接符时，自动更新规则示例
- 示例字段只读，防止手动修改

### 2. 数据验证
- 规则编号：必填
- 规则说明：必填
- 5个输入下拉框：必填（但可以选择"空字符串"）
- 5个连接符下拉框：可选

### 3. 编辑回显
- 编辑时自动解析JSON并回填到10个下拉框
- 自动生成规则示例

### 4. 用户友好
- 清晰的表单布局
- 输入和连接符分组显示
- 自动生成的示例帮助用户理解规则
