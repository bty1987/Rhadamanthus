# 主材算量避坑器 · 商业计划书

> **一句话定位**:选材期业主的"采购计算器+避坑雷达"——输入房型尺寸和铺贴方式,精确算出瓷砖/地板/壁纸等各类主材需要多少片/箱/㎡(带损耗系数),并用"买多了退货折腾、买少了补货色差"的真实数据,让业主一次买对,省下数千元退货损失和无尽的来回折腾。
>
> 版本:v1.0 ｜ 日期:2026-08-14 ｜ 作者:白添宇
> 文档定位:**全程陪审链的选材期产品(P2)**,填补报价与施工之间的空白段。它复用算量引擎(施工算量→主材算量的同源迁移),是 v3 全程旅程覆盖的关键一环。整体战略框架见《家装数字化_产品矩阵战略与创意全景.md》。

## 0. 产品的战略位置:填补选材期空白

全程陪审链里,报价X光机管"施工前",增项防火墙管"施工中",但中间有一段空白:

```
报价X光机(报价期) → 【??? 选材期 ???】 → 增项防火墙(施工中)
                         ↑
                   业主自购主材的高发坑区
```

选材期是业主**脱离装企、独立决策**的环节——瓷砖地板壁纸等主材,业主自己(或跟设计师)去建材市场买。此时没有装企报价单可审,也没有增项可判,但**有一类全新的、被忽视的损失:买错量**。

> **核心论断**:报价和增项是"被装企多收钱"的损失,主材买错量是"自己折腾+隐性浪费"的损失。后者更隐蔽——业主甚至意识不到自己亏了,只觉得"装修真麻烦"。

## 1. 机会:主材买错量是真实且巨大的痛点(实测数据)

### 1.1 市场背景

装修主材(瓷砖/地板/卫浴/橱柜/门窗/电器…)占装修总预算的 40-60%。这些材料业主往往自行采购(半包模式)或通过装企代购,但**采购量怎么算,是业主最大的认知盲区**:
- 瓷砖按"片"卖,但业主只会算"墙面面积",不会换算片数
- 不同铺贴方式(正铺/斜铺/人字拼/鱼骨拼)损耗率差 5-15%
- 异形空间(弧形墙、斜顶、柱子)增量算不准
- 地板按"㎡"卖,但每箱固定㎡数,买多了整箱退不了

### 1.2 实测核心数据(40万条主材退货)

查 `material.materialrefund` + `sales.salesrefunds`,主材退货是真实且巨大的市场:

| 指标 | 实测值 |
|---|---|
| **主材退货总盘** | **4.9 亿元(status=3 已完成)** |
| **退货单数** | **24 万单** |
| 销售退货盘(salesrefunds) | 2.88 亿元 / 40 万单 |
| 平均退货金额 | 2,000-14,000 元/单 |

### 1.3 退货品类分布——瓷砖是绝对大头

| 品类 | 退货单数 | 退货金额(万元) | 特征 |
|---|---|---|---|
| **瓷砖** | **90,573** | **12,282** | 退货量最大,单次均值 44,893 块(整批退) |
| 卫浴 | 17,201 | 7,975 | 单价高 |
| 电器 | 12,345 | 6,580 | |
| **地板** | **25,999** | **4,996** | 按㎡/根/个多种计量并存 |
| 木门 | 10,078 | 2,778 | |
| 橱柜 | 3,315 | 2,447 | |
| 吊顶 | 10,420 | 1,502 | |
| 壁纸 | 4,577 | 784 | 按米/个/套混乱 |

**关键洞察**:瓷砖退货 1.2 亿元(9万单),占主材退货总盘的 25%。而且**单次退货均值高达 44,893 块**——这说明业主一旦算错,是整批整批地退,损失巨大。

### 1.4 退货原因采样——全是"区域买错/多买"

| 退货备注 | 次数 |
|---|---|
| 厨墙 | 1,757 |
| 卫墙 | 1,140 |
| 卫地 | 1,132 |
| 厨地 | 463 |
| 厅地 | 325 |

**解读**:退货备注全是"厨房墙砖""卫生间墙砖""卫生间地砖"——业主**按区域算错了用量**,多买的整批退回。这不是"不喜欢了"的退货,是**算量错误的直接代价**。

### 1.5 计量单位混乱——算不准的根源

瓷砖的计量单位多达 8 种(块/米/个/㎡/项/公里/延米/片/组),地板有 6 种(㎡/根/个/米/支/组),壁纸 5 种。**同一品类在不同品牌/不同渠道用不同计量单位**,业主根本换算不过来:

| 品类 | 主要计量单位 | 算量难点 |
|---|---|---|
| 瓷砖 | 块(主流) | 面积→片数换算 + 损耗 + 异形增量 |
| 地板 | ㎡/根 | 每箱固定㎡数,零散退不了 |
| 壁纸 | 米/个/套 | 墙面面积→卷/米换算 + 对花损耗 |

> 这就是机会:**把混乱的计量单位统一成业主能输入的"房型尺寸",输出精确采购量。** 市面有瓷砖计算器,但都很粗糙(只算面积×损耗),无人做"全品类+异形+多种铺贴方式"的专业算量。

## 2. 核心算法:算量引擎的跨场景复用

### 2.1 从施工算量到主材算量的同源迁移

我们之前逆向的施工算量公式,核心是**从功能区尺寸推算工程量**。这套逻辑无缝迁移到主材算量:

| 场景 | 施工算量(报价X光机) | 主材算量(本产品) |
|---|---|---|
| 输入 | 周长/层高/门窗/梁 | 周长/层高/门窗/梁(同样) |
| 公式 | 周长×层高 − 门窗/2 − 厨卫扣顶20% | 周长×层高 − 门窗 + 损耗系数 |
| 输出 | 施工㎡ | 瓷砖片数/地板㎡/壁纸卷数 |

**同一个引擎,两个产品,边际成本极低。** 这是 v3 视野扩大后发现的资产复用红利——施工算量建好的参数化逻辑,改个输出层就是主材算量器。

### 2.2 主材算量的三层算法

```
第一层:基础用量
  墙面瓷砖 = (周长×层高 − 门窗面积) ÷ 单片瓷砖面积
  地板 = 地面面积 ÷ 单片地板面积(或直接按㎡)

第二层:损耗系数(按铺贴方式)
  正铺(常规):+5%
  斜铺/菱形:+8-10%
  人字拼/鱼骨拼:+12-15%
  异形空间(弧形/斜顶):额外 +5-10%

第三层:起订量修正
  瓷砖按箱卖 → 向上取整到整箱
  地板按包卖 → 向上取整到整包
  + 预留 1-2 箱备用(防后期破损补不到同批次)
```

### 2.3 独家知识:瓷砖规格与片数换算库

基于退货数据,我们沉淀了主流瓷砖规格的换算库(部分):

| 规格 | 单片面积 | 每㎡片数 | 典型用途 |
|---|---|---|---|
| 300×600 | 0.18㎡ | 5.56 片 | 厨卫墙砖 |
| 400×800 | 0.32㎡ | 3.13 片 | 客厅墙砖 |
| 600×600 | 0.36㎡ | 2.78 片 | 地砖 |
| 800×800 | 0.64㎡ | 1.56 片 | 客厅地砖 |
| 600×1200 | 0.72㎡ | 1.39 片 | 大规格地砖/上墙 |
| 750×1500 | 1.125㎡ | 0.89 片 | 岩板/大板 |

> 这个换算库 + 铺贴方式损耗系数,是产品的核心知识资产,市面竞品没有这么细。

## 3. 产品方案

### 3.1 MVP(4-6 周)

```
业主打开「主材算量避坑器」小程序
  ↓
输入房型尺寸(手输 或 导入户型图 或 拍照量房)
  ↓
选择品类 + 规格 + 铺贴方式
  例:厨房墙砖 300×600 正铺 / 客厅地砖 800×800 斜铺
  ↓
输出【主材采购清单】:
  📦 厨房墙砖:需要 312 片(含5%损耗),建议买 330 片(11箱,每箱30片)
  📦 客厅地砖:需要 156 片(含8%损耗),建议买 160 片(10箱,每箱16片)
  💰 预估花费:墙砖 ¥3,300 + 地砖 ¥6,400 = ¥9,700
  ⚠️ 避坑提醒:
     - 瓷砖建议多买1-2箱备用,后期破损可能补不到同批次(色差)
     - 你选的斜铺损耗8%,比正铺多花 ¥500,确认接受?
     - 厨房墙砖到顶(2.4m)还是只贴2m?影响用量30%
```

### 3.2 完整版(3 个月)

| 功能 | 价值 |
|---|---|
| **铺贴方式损耗库** | 正铺/斜铺/人字拼/鱼骨拼等 10+ 种方式的精确损耗 |
| **异形空间增量** | 弧形墙/斜顶/柱子/飘窗的增量算法 |
| **品牌规格库** | 主流品牌(东鹏/马可波罗/蒙娜丽莎…)的规格+每箱片数 |
| **补货预警** | 告诉业主"你买的批次停产风险",是否需多备 |
| **与报价X光机协同** | 报价里的主材项 → 自动带入算量,交叉验证 |

### 3.3 与矩阵的协同

```
报价X光机(报价期)
  ↓ 报价单里的主材项(规格/数量)
主材算量避坑器(选材期)
  ↓ 复核装企算的主材量对不对 + 业主自购算量
增项防火墙(施工中)
  ↓ 主材相关的增项(如地砖上墙、瓷砖升级)
```

**协同价值**:报价X光机里的主材数量,直接喂给算量器复核——**装企报的瓷砖数量,和我们算的一对比,多报少报立刻现形**。

## 4. 痛点与付费逻辑

### 4.1 业主在选材时的无助

| 场景 | 业主状态 | 算量避坑器的价值 |
|---|---|---|
| 建材市场,销售问"要多少箱" | 凭感觉报,怕不够多买 | 精确算量,心里有底 |
| 不知道不同铺法损耗不同 | 正铺的量按斜铺算,少买了 | 按实际铺法算损耗 |
| 装企代购,不知道报的量对不对 | 全凭装企,可能多报吃回扣 | 复核装企采购量 |
| 多买了整箱退不了/退货折腾 | 退货来回跑,还可能扣折损 | 一次买对,省退货 |
| 买少了补货,批次不同有色差 | 后期补的瓷砖颜色对不上 | 预留备用+补货预警 |

### 4.2 付费逻辑(焦虑+实用双重驱动)

> 主材算量是**罕见的"焦虑+实用"双驱动**产品:既缓解焦虑(怕买错折腾),又有立即可见的实用价值(精确数字)。业主在建材市场当场就能用,用完就知道省了多少。**为"当场省下几千块退货损失+免去折腾"付 9.9-19.9 元,转化逻辑极顺。**

### 4.3 单位经济

- 客单:基础算量免费(引流) + 精算报告/全品类清单 9.9-19.9 元
- 成本:极低(纯算法,无数据库依赖)
- **获客**:报价X光机用户自然转化 + "瓷砖买多了退3万"类内容引流
- **高频**:一个业主装修会算 5-10 次主材(瓷砖/地板/壁纸/吊顶/橱柜…),单用户多次使用

## 5. 为什么是矩阵里的"隐藏王牌"

主材算量避坑器看似不如报价X光机"性感",但有几个独特优势:

| 优势 | 说明 |
|---|---|
| **技术最轻** | 纯算法,无数据库依赖,4周可上线(与合同审查并列最轻) |
| **引擎复用** | 施工算量→主材算量同源迁移,边际成本极低 |
| **数据飞轮** | 用户算量数据反哺规格库+损耗系数,越用越准 |
| **使用频次最高** | 一个业主用 5-10 次(每类主材一次),粘性远超单次审计 |
| **即时价值** | 当场出结果、当场省钱,转化路径最短 |
| **填补空白** | 选材期是全程旅程里唯一的"盲区",竞品都没覆盖 |

## 6. 市场进入与冷启动

### 6.1 内容冷启动(强素材)

| 爆款选题 | 杀伤力 |
|---|---|
| "装修买瓷砖,我多算了3000块的损耗" | 强(具体损失) |

| "瓷砖买少了补货,结果色差毁全屋" | 极强(恐惧驱动) |
| "装企代购的瓷砖,数量对不对你算过吗" | 强(戳穿代购) |

### 6.2 落地节点(P2,第 4-6 月)

| 子阶段 | 时间 | 动作 |
|---|---|---|
| P2.1 规格库 | 第 4 月 | 主流品牌瓷砖/地板规格+每箱片数+损耗系数库 |
| P2.2 MVP | 第 5 月 | 瓷砖+地板两类先上(占退货70%),房型输入→采购清单 |
| P2.3 协同 | 第 6 月 | 与报价X光机打通,复核装企主材量 |
| P2.4 扩品类 | 第 6 月+ | 壁纸/吊顶/橱柜等品类 |

## 7. 风险与应对

| 风险 | 等级 | 应对 |
|---|---|---|
| 规格库不全 | 🟡 中 | 先覆盖退货量最大的瓷砖/地板(70%),逐步扩展 |
| 业主户型输入门槛 | 🟡 中 | 支持手输/拍照/户型图导入多入口 |
| 损耗系数争议 | 🟢 低 | 按铺贴方式给出行业标准区间,说明依据 |
| 精度要求 | 🟡 中 | 定位"采购参考",建议多备1-2箱,容错设计 |

### 🔴 合规红线

1. 规格库基于公开品牌参数 + 实测退货数据(脱敏聚合),不用雇主私有采购数据
2. 损耗系数引用行业标准,标注来源
3. 定位"采购辅助参考",非绝对精确,免责

## 9. 与战略矩阵的契合

| 战略维度 | 主材算量的贡献 |
