## 接口概述

本接口用于 HR 系统与方林信息平台之间的数据同步，包括：
- 职位信息同步
- 部门信息同步
- 用户信息同步

---

## 基础信息

| 项目 | 值 |
|------|-----|
| 基础URL | `http://[服务器地址]/` |
| Content-Type | `application/x-www-form-urlencoded` |
| 响应格式 | JSON |
| 认证方式 | session认证 |

---

## 1. 同步职位信息

### 接口地址
```
POST /syncDuty.do
```

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 是 | 职位名称 |
| code | String | 否 | 职位编码（更新时提供） |
| type | Integer | 是 | 部门类型ID |
| org_code | String | 否 | 部门编号（保留但未使用） |
| status | Integer | 否 | 状态：1启用，2禁用 |
| leader_flag | Integer | 否 | 是否领导岗：0否，1是 |

### 请求示例

```bash
# 新增职位
curl -X POST "http://server/syncDuty.do" \
  -d "name=司机" \
  -d "code=POST9526" \
  -d "type=1" \
  -d "status=1" \
  -d "leader_flag=0"
```

### 响应示例

```json
{
    "errorCode": 0,
    "errorMsg": "",
    "data": "POST9526"
}
```

## 2. 同步部门信息

### 接口地址
```
POST /syncDepartment.do
```

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 是 | 部门名称 |
| code | String | 否 | 信息平台部门ID或编码（更新时提供） |
| type | Integer | 是 | 部门类型ID |
| org_code | String | 是 | 公司ID（对应 company.cid） |
| parent_code | String | 否 | 信息平台父级编码 |
| status | Integer | 否 | 状态：1启用，2禁用 |
| order_value | Integer | 否 | 排序值 |
| leader_code | String | 否 | 部门经理工号 |
| posts | String | 否 | 定岗映射信息（JSON字符串） |

### posts 参数格式
```json
{
  "1": 10,  // 岗位码 => 人员上限值
  "2": 20
}
```

### 请求示例

```bash
# 新增部门
curl -X POST "http://server/syncDepartment.do" \
  -d "name=设计一部" \
  -d "code=DEPT9526" \
  -d "type=1" \
  -d "org_code=1" \
  -d "parent_code=DEPT9525" \
  -d "status=1" \
  -d "order_value=1" \
  -d "leader_code=FL-09527" \
  -d 'posts={"1": 10, "2": 20}'
```

### 响应示例

```json
{
    "errorCode": 0,
    "errorMsg": "",
    "data": "DEPT9526"
}
```

## 3. 同步用户信息

### 接口地址
```
POST /syncUser.do
```

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| code | String | 否 | 用户工号（更新时提供） |
| name | String | 是 | 姓名 |
| current_name | String | 否 | 现用名（默认使用name） |
| gender | Integer | 否 | 性别：0女，1男（默认1） |
| identity | String | 是 | 身份证号 |
| phone | String | 是 | 手机号 |
| login_id | String | 否 | 登录用户名（默认使用userId） |
| dept_id | Integer | 是 | 部门ID |
| duty_id | Long | 是 | 职位ID |
| company | Integer | 是 | 公司ID（user.company） |
| status | Integer | 否 | 状态：1在职，0离职，2停薪留职（默认1） |

### 请求示例

```bash
# 新增用户
curl -X POST "http://server/syncUser.do" \
  -d "name=张三" \
  -d "current_name=张三" \
  -d "gender=1" \
  -d "identity=210xxx..." \
  -d "phone=13800138000" \
  -d "login_id=zhangsan" \
  -d "dept_id=123" \
  -d "duty_id=456" \
  -d "company=1" \
  -d "status=1"
```

### 响应示例

```json
{
    "errorCode": 0,
    "errorMsg": "",
    "data": {
        "code": "12345",
        "belong_org_code": "1",
        "userId": "FL-09527"
    }
}
```

### 响应字段说明

| 字段 | 说明 |
|------|------|
| code | user.uid |
| belong_org_code | user.company |
| userId | user.userId（工号） |

## 注意事项

1. **参数验证**: 所有接口都有必填参数验证，缺少必填参数会返回对应错误码
2. **更新逻辑**: 提供 code 参数时执行更新操作，否则执行新增操作
3. **posts 参数**: 定岗映射信息需要是有效的 JSON 字符串格式
4. **session认证**: 调用接口前需要先登录获取有效的 session
