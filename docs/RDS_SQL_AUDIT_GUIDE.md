# RDS SQL洞察（审计）配置指南

> 版本：v1.0
> 日期：2026-04-11
> 适用实例：rr-2ze11ccr650aw2c79oo.mysql.rds.aliyuncs.com

---

## 一、功能说明

RDS SQL洞察是阿里云提供的数据库审计服务，可以自动记录所有SQL执行情况，包括：
- SQL语句内容
- 执行时间
- 执行用户
- 客户端IP
- 执行耗时
- 影响行数

---

## 二、配置步骤

### 步骤1：登录阿里云控制台

1. 访问 https://rds.aliyun.com
2. 登录账号

### 步骤2：进入RDS实例

1. 点击左侧菜单 **RDS管理** → **实例列表**
2. 找到实例：`rr-2ze11ccr650aw2c79oo`
3. 点击实例名称进入详情页

### 步骤3：开启SQL洞察

1. 在左侧菜单中找到 **安全性** 或 **SQL洞察**
2. 点击 **SQL审计** 或 **SQL洞察**
3. 点击 **开启SQL审计** 按钮

### 步骤4：配置参数

| 参数 | 推荐值 | 说明 |
|-----|-------|------|
| 存储时长 | 30天 | 审计日志保留时间，可选1-1825天 |
| 审计粒度 | 全量审计 | 记录所有SQL语句 |
| 高频语句 | 开启 | 统计高频执行的SQL |

### 步骤5：确认开启

点击 **确定** 按钮，等待约1-5分钟生效。

---

## 三、查询审计日志

### 方式1：控制台查询

1. 进入 **SQL洞察** → **SQL审计**
2. 设置筛选条件：
   - 时间范围：选择查询时间段
   - 数据库：选择特定数据库（可选）
   - 用户名：输入用户名（如 fanglin1918）
   - 关键字：输入SQL关键词（可选）
3. 点击 **查询** 按钮

### 方式2：导出审计日志

1. 在SQL审计页面，点击 **导出** 按钮
2. 选择时间范围和格式（CSV/Excel）
3. 点击 **确定** 下载

---

## 四、常用审计查询

### 查询敏感表访问记录

在控制台筛选条件中设置：
- **关键字**：`customer` 或 `communion.customer`
- **时间范围**：选择最近7天/30天

### 查询特定用户操作

- **用户名**：`fanglin1918` / `BI` / `PM` 等

### 查询异常操作

- **关键字**：`DROP` / `DELETE` / `TRUNCATE`
- **执行耗时**：`> 1000ms`（慢查询）

## 六、注意事项

1. **性能影响**：SQL审计对性能影响极小（<1%）
2. **存储空间**：审计日志占用RDS存储空间，注意监控
3. **合规要求**：根据合规要求设置保留时长（建议30天以上）
4. **权限控制**：只有主账号可以查看审计日志
