# 企业微信扫码登录页面跳转控制实现方案

> 修改时间：2025-12-21
> 修改文件：`WebContent/js/xlogin.js`、`WebContent/js/api/common.js`

## 概述

本次修改实现了企业微信二维码扫码登录成功后对页面跳转的完全控制，用户可以选择停留在当前页面或手动跳转到系统主页面，避免了自动跳转带来的不便。

## 核心功能

### 1. 页面跳转拦截器
- **拦截时机**：页面加载时自动设置，监听 `popstate` 和 `hashchange` 事件
- **拦截目标**：企业微信回调参数（`code` 和 `state`）
- **防重复处理**：使用 `window.workWechatProcessed` 标记避免重复触发

### 2. 智能验证机制
- **主验证接口**：`verifyWorkWechatLogin.do`（可选实现）
- **备用验证接口**：`current.do`（系统现有接口）
- **兜底机制**：当接口不可用时，使用默认验证通过

### 3. 用户体验优化
- **登录成功界面**：显示成功状态和操作选项
- **可控跳转**：用户可选择是否进入系统
- **URL清理**：自动清除回调参数，避免重复处理

## 主要修改内容

### 文件1：`WebContent/js/xlogin.js`

#### 新增函数

1. **`setupRedirectInterceptor()`**
   - 设置页面跳转拦截器
   - 监听 `popstate` 和 `hashchange` 事件
   - 拦截企业微信回调并处理

2. **`handleWorkWechatCallbackWithoutRedirect(code, state)`**
   - 处理企业微信回调但不自动跳转
   - 调用验证接口验证登录状态
   - 根据验证结果显示相应的UI

3. **`verifyWorkWechatLoginStatus(code, state, callback)`**
   - 调用自有接口验证登录状态
   - 支持主接口和备用接口的回退机制
   - 返回用户信息和跳转URL

4. **`cleanUrlParameters()`**
   - 清理URL中的回调参数
   - 使用 `history.replaceState` 避免页面刷新

5. **`shouldRedirect(redirectUrl)`**
   - 业务逻辑判断，决定是否需要自动跳转
   - 默认返回 `false`，让用户自主选择

6. **`showLoginSuccessAndStay()`**
   - 显示登录成功界面
   - 提供"进入系统"和"重新登录"按钮

7. **`performControlledRedirect(redirectUrl)`**
   - 执行可控的页面跳转
   - 显示跳转提示和倒计时

#### 修改函数

1. **`initPage()`**
   - 在初始化时调用 `setupRedirectInterceptor()`

2. **`checkLoginCallback()`**
   - 添加重复处理检查，避免与拦截器冲突

## 使用流程

### 1. 扫码登录流程
```
用户扫码 → 企业微信验证 → 回调到 xlogin.html
    ↓
拦截器检测到回调参数 → 阻止默认跳转
    ↓
调用验证接口验证登录状态 → 验证成功
    ↓
显示登录成功界面 → 用户选择操作
```

### 2. 用户操作选项
- **进入系统**：调用 `goToSystem()` 跳转到主页面
- **重新登录**：刷新页面重新开始登录流程

### 3. 验证接口响应格式（推荐）

```json
{
  "errorCode": 0,
  "errorMsg": "",
  "userInfo": {
    "userId": "12345",
    "userName": "张三",
    "userRole": "designer",
    "permissions": ["dashboard", "order"]
  },
  "redirectUrl": "/dashboard.html"  // 可选，指定跳转页面
}
```

## 业务逻辑扩展

### 自定义跳转规则
可以在 `shouldRedirect()` 函数中添加业务逻辑：

```javascript
function shouldRedirect(redirectUrl) {
    // 示例：管理员用户自动跳转到管理页面
    if (userInfo.userRole === 'admin') {
        return true;  // 自动跳转
    }

    // 示例：设计师用户停留在当前页面
    if (userInfo.userRole === 'designer') {
        return false;  // 不自动跳转
    }

    // 默认不自动跳转
    return false;
}
```

### 后端接口实现建议

如果需要实现专用的验证接口 `verifyWorkWechatLogin.do`：

```java
// 后端伪代码
@PostMapping("/verifyWorkWechatLogin.do")
public Response verifyWorkWechatLogin(@RequestParam String code, @RequestParam String state) {
    // 1. 使用 code 和 state 向企业微信服务器获取用户信息
    WeChatUser wechatUser = wechatService.getUserInfo(code, state);

    // 2. 验证用户权限和状态
    User user = userService.getUserByWeChatId(wechatUser.getOpenId());
    if (user == null || !user.isActive()) {
        return Response.error("用户不存在或已禁用");
    }

    // 3. 生成登录会话
    String token = sessionService.createToken(user);

    // 4. 返回用户信息和跳转URL
    return Response.success()
        .setData("userInfo", convertToUserInfo(user))
        .setData("token", token)
        .setData("redirectUrl", getRedirectUrl(user));
}
```
