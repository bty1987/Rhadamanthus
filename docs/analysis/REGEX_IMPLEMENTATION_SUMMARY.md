# 楼盘命名规则 - 正则表达式版本实现总结

> 更新时间：2025-01-01
> 关键改进：使用标准正则表达式作为value值

---

## ✅ 核心改进

### 问题
之前的实现使用代码值（如 `NUM_ALPHA`、`MEN`），不符合正则表达式规范。

### 解决方案
**直接使用正则表达式作为下拉框的value值**，同时生成两个输出：
1. **正则表达式** - 用于程序校验
2. **人类可读示例** - 用于用户理解

---

## 📋 下拉框选项配置

### 输入字段（正则表达式）

| 显示文本 | Value（正则表达式） | 示例 |
|---------|-------------------|------|
| 空字符串 | `` (空字符串) | '' |
| 数字字母 | `[0-9]+[A-Za-z]+` | 1A, 23B |
| 字母数字 | `[A-Za-z]+[0-9]+` | A1, AB2 |
| 数字 | `[0-9]+` | 1, 23, 456 |
| 字母 | `[A-Za-z]+` | A, AB, ABC |

**正则说明**：
- `[0-9]+` - 一个或多个数字
- `[A-Za-z]+` - 一个或多个字母
- `+` 表示"一个或多个"

### 连接符字段（字面值）

| 显示文本 | Value（字面值） | 实际连接符 |
|---------|----------------|-----------|
| 空字符串 | `` (空字符串) | - |
| - | `-` | - |
| / | `/` | / |
| 门 | `门` | 门 |
| 门- | `门-` | 门- |
| 门# | `门#` | 门# |
| 座 | `座` | 座 |
| 座- | `座-` | 座- |
| 座# | `座#` | 座# |
| 甲 | `甲` | 甲 |

#### 2. 自动生成两个输出
```javascript
function updateRuleExample() {
    var regex = '';      // 正则表达式
    var example = '';    // 人类可读示例

    for (var i = 0; i < 5; i++) {
        var inputValue = buildingNameRule.items.inputs[i].val();
        var separatorValue = buildingNameRule.items.separators[i].val();

        // 生成正则表达式（直接使用value）
        if (inputValue) regex += inputValue;
        if (separatorValue) regex += separatorValue;

        // 生成人类可读示例（使用映射）
        if (inputValue) {
            var inputText = getInputExampleText(inputValue);
            example += inputText;
        }
        if (separatorValue) {
            example += separatorValue;
        }
    }

    // 同时更新两个字段
    buildingNameRule.items.ruleRegex.val(regex);      // 正则表达式
    buildingNameRule.items.ruleExample.val(example);   // 人类可读
}
```

#### 3. 示例文本映射
```javascript
function getInputExampleText(value) {
    var examples = {
        '[0-9]+[A-Za-z]+': '1A',      // 正则 → 示例
        '[A-Za-z]+[0-9]+': 'A1',
        '[0-9]+': '1',
        '[A-Za-z]+': 'A',
        '': ''
    };
    return examples[value] || '';
}
```

## 🎯 使用场景

### 前端校验
```javascript
// 保存后获取规则
var rule = {
    inputs: ["[0-9]+[A-Za-z]+", "[0-9]+"],
    separators: ["-", "门"]
};

// 拼接成正则表达式
var regex = rule.inputs[0] + rule.separators[0] +
           rule.inputs[1] + rule.separators[1];
// 结果: "[0-9]+[A-Za-z]+-[0-9]+门"

// 用于校验
var pattern = new RegExp('^' + regex + '$');
pattern.test('1A-2门');  // true
pattern.test('ABC-2门'); // false
```

### 后端校验（Java）
```java
import java.util.regex.Pattern;

String regex = "[0-9]+[A-Za-z]+-[0-9]+门";
Pattern pattern = Pattern.compile("^" + regex + "$");

pattern.matcher("1A-2门").matches();  // true
pattern.matcher("ABC-2门").matches(); // false
```
