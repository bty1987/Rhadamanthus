# 前端页面样式规范与风格说明

> **状态**:反哺参考(2026-10-26),来源为方林两套现代前端的实读提取,供本项目前端改造与迁移(view-*)对齐使用。
> **来源**:`D:\Git\view-decoration-pc`(业务系统风格,653 个视图的全量统计)与 `D:\Git\view-yy-pc` 高管驾驶舱(`src/views/cockpit/` 8 大看板 + `docs/毛利率页面配色方案.md`,数据可视化风格)。
> **定位**:两套体系各管一类页面——**业务系统风格**管日常操作页(列表/表单/详情),**数据看板风格**管报表与驾驶舱页。本项目迁移线(docs/mover/,目标栈即 view-decoration-pc 同款 Vue3+Arco)照第二套章节执行;报表平台(metric_* + echarts)照第三章执行。
> **数值说明**:本文所有色值/字号均为源项目代码实测值,非理想化杜撰;个别处标注"拍板偏好"的是驾驶舱项目已确认的高管端可读性口径。

---

## 一、两套风格的定位与选用口径

| 体系 | 源 | 适用页面 | 视觉气质 |
|---|---|---|---|
| 业务系统风格 | view-decoration-pc | 列表页、表单页、详情、审批、配置——日常操作 | Arco 紧凑工具风:白底、4px 圆角、#dbdbdb 细边框、紧凑表格 |
| 数据看板风格 | view-yy-pc/cockpit | 驾驶舱、看板、报表大屏、指标汇总页 | 多主题卡片墙:指标大数、低饱和图表、柔和渐变横幅 |

一句话:**操作页要"不显眼、高效、一致",看板页要"主数够大、层级分明、一屏讲完"**。两类页面不互相混用——列表页不搞渐变横幅,看板页不套列表筛选栏。

## 二、业务系统风格(view-decoration-pc)

### 2.1 技术底座

- Vue 3.5 + TypeScript + Arco Design Vue 2.57(按需引入)+ sass;**无 tailwind、无项目自有图表库**。
- 全局只注入 `variables.scss`(当前为空占位)——**设计 token 全部直接用 Arco CSS 变量**(`var(--color-text-1)`、`rgb(var(--primary-6))`),不另建变量体系。
- 图标 = Arco Icon + CDN iconfont(`IconFont` 组件);图片资源统一上 OSS(`static-res/`)。

### 2.2 色板(硬约定速查)

| 语义 | 色值 | 备注 |
|---|---|---|
| 主色 | `#165dff`(= Arco arcoblue-6) | 全站按钮/链接/激活态 |
| 分页激活 | `#3762ec` | 页码格选中底 |
| 危险/红 | `#f53f3f` | 必填星号、禁用标注、danger 按钮 |
| 成功/绿 | `#00b42a` | |
| 警告/橙 | `#ff7d00`(金黄 `#f7ba1e` 少量) | |
| 输入/筛选框描边 | **`#dbdbdb`**(全局覆盖 Arco 默认) | 配 `border-radius:4px`、透明底 |
| 内容区描边 | `#e2e2e2` | 面板边框 |
| 表头底 | `#FAFAFA`,表头字 `rgba(0,0,0,0.6)` | |
| 主文本 | `rgba(0,0,0,0.85)`(激活)/`#1d2129` | 辅助 `#666`/`#86909c` |
| 树/列表 hover 选中底 | `#eceff4` | |
| 内容区顶部渐变 | `linear-gradient(180deg,#f2f6fc 0%,rgba(255,255,255,0) 31%)` | 唯一的页面级渐变 |

状态标签用 Arco 预设名,每页定义 `statusColorMap`:待处理→`gray`/`orange`、处理中→`blue`、成功→`green`、拒绝→`red`、作废→`#86909c`。

### 2.3 字体与字号层级

- 基准 **14px**(html body),抗锯齿;辅助 12/13px(使用量最大:12px×253、14px×246、16px×146)。
- 层级惯例:辅助文字 12–13px → 表格 13px → 正文 14px → **区块标题 16px/500** → **页面标题 18px/500-600** → 登录主标 30px/600;指标数值 600。
- 不声明全局 font-family(跟随 Arco 默认栈);打印模板宋体、合同预览等宽字体属场景特例。

### 2.4 间距 / 圆角 / 阴影

- 页面容器 `.page-container { padding: 20px 15px 15px 20px; }`(137+ 页面同构);筛选项间距 `margin-right:15px`;表单项 `margin-bottom:10px`;分页区 `padding:15px 10px 15px 0` 右对齐。
- 圆角:**4px 绝对主导**(控件/卡片,230 处)、6px(内容面板/树项)、50%(头像);阴影:**标准卡片阴影 `0 1px 10px 0 rgba(38,52,74,0.12)`**。
- 全站水印:`a-watermark` 用户名+手机后四位(alpha 0.5),layout 与抽屉两层——审计追溯,新前端必须保留。

### 2.5 页面骨架(345+ 列表页同构)

```
.page-container
├── 顶部行 .my-flex-between
│   ├── 左:DynamicForm 筛选栏(inline,带边框筛选盒 #dbdbdb/4px,竖分隔线)
│   └── 右:a-space 主按钮组(v-permission 控权)
├── DynamicTable(表头 #FAFAFA、单元格 5px 10px 紧凑、序号列 70px fixed、非斑马纹)
└── 右对齐分页(页码格 32×32,激活 #3762ec 白字)
```

- 主从页:左 250px 树面板 + 右表格(`page-xxx-left/right` 类名模式)。
- 编辑/详情:**MDrawer 抽屉**(默认 450px,全屏=视口−菜单宽),表单 `label-col 6 / wrapper-col 15` 或 vertical 双列;详情区块 `.descriptions-wrap`(标题 16px/500,label `--color-text-3`)。
- 布局框架:固定顶栏 60px + 固定左侧栏 220px(收起 48px),内容面板圆角 6px + `#e2e2e2` 边框,路由 fade 过渡。

### 2.6 组件硬约定

- 按钮:primary ×608 / text ×335 / outline ×102;**size 以 small(×920)/mini(×314) 为主**(紧凑);危险操作 `status="danger"`;操作列 `<a-button size="small">` 组。
- 筛选控件宽度:text/number/select 150px、range 230px、datetimerange 340px、cascader 200px;筛选盒带竖分隔线是识别性特征。
- 页签 MTabs:16px/500,激活加粗 + 3px 墨条;数量 `(n)` 跟随,提醒红点 `#f53f3f`。
- 弹窗:确认框统一 `.modal-warn`(圆角 6px、body 居中、footer 右对齐);常规 modal 350–650px。

### 2.7 命名与写法

- `<style scoped lang="scss">` 为主;class 全 kebab-case,BEM-lite(`&-` 后缀嵌套,不用 `__`/`--` 符号);工具类前缀 `.my-*`(`my-flex` 族、`my-ellipsis`、`my-multi-ellipsis--l2`)。
- 全局覆盖 Arco 统一在 global.scss(输入类 `#dbdbdb`+4px+透明底),局部覆盖用 `:deep()`;少量非 scoped 块只用于全局性 Arco 覆盖。
- 质量工具:stylelint(standard+rational-order+vue,属性排序)、prettier(无分号单引号 100 列);README「开发规范」章节定义了文件/变量/常量命名与 git 提交前缀。

## 三、数据看板风格(view-yy-pc 驾驶舱)

### 3.1 四个子体系(按页面类型对号入座)

| 子体系 | 主题 | 适用 |
|---|---|---|
| 主材驾驶舱家族 | 蓝灰底 `#f1f3f7`、白卡无边框、**红涨绿跌** | 经营/销售/款项/结算类看板 |
| 管理看板 | 暖橙、五色 accent 循环、橙暖表格 | 管理汇总/排名类 |
| 月例会看板 | 蓝主题、**container query 自适应(clamp)**、达成/同环比四档分色 | 例会汇报、目标达成类 |
| Excel 复刻表 | 粗黑外框、深红表头 `#9E1E1A`、黑白网格 | 财务口径公示表(照搬 Excel 版式) |

### 3.2 图表:统一低饱和主题(chart-theme)

- 分类色序列(9 色循环):blue `#4C7CE7`、teal `#54AFA4`、purple `#8E83D4`、sky `#74B4D8`、indigo `#7487C5`、rose `#D588A3`、slate `#7E94AD`、orange `#DE9B75`、green `#8DBB91`;准确色值以 `view-yy-pc/src/utils/chart-theme.ts` 为权威。
- **语义色与分类色分开**:success `#58A58B`、warning `#D8A252`、danger `#D97070`;文本 `#334155`/muted `#64748B`、网格线 `#E9EEF5` 虚线。
- 主题规范:白底、字体 `PingFang SC, Microsoft YaHei`;title 15px/600、legend 12px、tooltip 白底圆角 8;init 时传入主题,**不覆盖各页指标/刻度/业务格式化**。
- 柱状图:barWidth 24–38、顶部圆角 `[4,4,0,0]`、顶部 label;折线:圆点 symbol 6、线宽 2.5;饼图白描边 2px。

### 3.3 指标卡体系

| 元素 | 规格(实测区间) |
|---|---|
| 主数 | **29–32px、字重 600–800、line-height 1~1.1、`font-variant-numeric: tabular-nums`、色 `#252525`/`#10294e`**(月例会页以 `clamp(22px, 11.5cqw, 32px)/700` 自适应) |
| 单位 | 主数的 0.73–0.76em(约 21–23px),或 12px/600 |
| 卡标题 | 13px/500-600,`#243247`,与主数间距 12px |
| 同比/环比标注 | **11–12px,`#748198`**,数值部分 600 加粗;格式 `+x.xx%↑ / -x.xx%↓`(带符号带箭头) |
| 卡片 | 白底、radius 6–12px、细边框、轻阴影 `0 2px 8px rgba(29,33,41,0.04)`、顶部 4px accent 纯色条;网格 gap 12px |

**高管端可读性偏好(驾驶舱项目拍板,高管类页面执行底线)**:主数 ≥32px、同比环比标注 ≥16px 并加粗、最小标注 ≥12.5px——"高管的眼睛不是显微镜"。代码中月例会页的 clamp 上限 32px 与此吻合;新做高管类看板按拍板值执行,普通报表页可按 3.3 实测区间下探。

### 3.4 语义色两套口径(必须按场景选对,禁止混用)

- **红涨绿跌**(主材家族):同比/环比上涨=红 `#dc534b`/`#ed5a5a`,下跌=绿 `#119b3b`/`#0b9d64`——中国股市惯例,用于"数值涨跌"语境。
- **好绿差红**(月例会分档):达标=绿、差=红——用于"目标达成好坏"语境。
- 分档规则(月例会,硬性注释):达成率 ≥100% 绿 `#009a29`、80–100% 黑、60–80% 黄 `#d97500`、<60% 红 `#e8352e`(配同色 10% 柔和底);同比/环比 ≥+10% 绿、±10% 内黑、-30~-10% 黄、≤-30% 红。
- R项目 落地口径建议:销售/业绩类页(看涨跌)用红涨绿跌;管理线/达成率类页(看好坏)用好绿差红。

### 3.5 配色使用原则(docs/毛利率页面配色方案.md,利润线页面统一规范)

- 色板:主色活力红 `#F53F3F`(悬停 `#D9363E`、浅底 `#FFF1F0`);页面底冷灰白 `#F6F8FB`、卡片纯白;主标题 `#24324A`、正文 `#52637C`、辅助 `#94A3B8`;边框雾灰 `#E6EBF2`;正向青绿 `#11A675`、警告橙黄 `#E69A12`、图表辅助线蓝 `#377CF6`。
- 四条原则:①红色只用于关键状态与主操作,不大面积铺满;②同一页面同一语义恒同色;③正负向必须明显区分;④文字优先深灰蓝系保证层级。

### 3.6 进度条与渐变(硬规则)

- **进度条一律纯色**(全部实测无一渐变):`a-progress` 单色 + 轨道 `#edf0f6`;自定义轨道 4px 高。
- **渐变只用于大面积背景/英雄横幅与整卡填充**:`linear-gradient(135deg,主色→亮色)`、页面底 `180deg` 柔和纵向渐变;小元素(卡顶条、标题竖条)全部纯色。
- 英雄头部范式:全宽渐变横幅(大圆角大阴影)+ 左侧 eyebrow(11px/700 大写)→ h1 28–29px/800 白 → 副题 14px 白 72% → 状态胶囊(999px 圆角、发光圆点);右侧玻璃操作区(白 8% 底/14% 边)。

### 3.7 数字格式化(硬规则)

- 金额:**万元两位小数** `(value/10000).toFixed(2)`;界面万元、Excel 导出保留元(`#,##0` 等 numberFormat)。
- 百分比两位小数(`toFixed(2)%`);率类 1 位小数;整数 `toLocaleString('zh-CN')`;**带符号**正数加 `+`;**空值一律显示 `—`,禁止显示 0**。
- 所有数字列 `tabular-nums`。

### 3.8 表格风格(看板类)

- 榜单表:12px tabular-nums、th 彩底白字 sticky(`#6487cf`)、奇行 `#f2f6fd`、hover `#e6efff`、序号列+姓名列双 sticky。
- 达成类表:表头蓝色渐变 `#eef3ff→#e3ecff`、斑马纹、悬停高亮、合计行 `#fff7dc/#7a4100/700`。
- 财务复刻表:外框 2px 黑、组间黑线组内细线(对齐 Excel 版式)。
- 金银铜徽章:24–26px 圆形,金 `#9A6A00/#FFF1C7`、银 `#64748B/#E8EDF3`、铜 `#9A5B32/#F5DDCE`。
