# Select 宽度修复说明

> 更新时间：2025-01-01

---

## ✅ 已修复

### 问题
内联样式 `width: 150px` 不生效，下拉框过宽导致不在一行显示。

### 解决方案
使用 **Bootstrap 栅格系统** 代替内联样式。

---

## 📐 新的宽度控制

### Bootstrap 栅格类
```html
<!-- 输入框 -->
<div class="col-xs-6 col-sm-1-5" style="padding: 0 5px 5px 0;">
    <select id="input1" class="rule-input v_required form-control"></select>
</div>

<!-- 连接符 -->
<div class="col-xs-6 col-sm-1" style="padding: 0 5px 5px 0;">
    <select id="separator1" class="rule-separator form-control"></select>
</div>
```

### 栅格说明
| 类名 | 小屏幕(<768px) | 中等屏幕(≥768px) | 说明 |
|------|----------------|-------------------|------|
| `col-xs-6` | 6/12格 (50%) | - | 小屏幕占一半 |
| `col-sm-1-5` | - | 1.5/12格 (12.5%) | 输入框宽度 |
| `col-sm-1` | - | 1/12格 (8.3%) | 连接符宽度 |

### 总宽度计算（中等屏幕）
```
5个输入框 × 1.5格 = 7.5格
5个连接符 × 1格   = 5格
总计                 = 12.5格（略超，会自动换行部分）
```

实际显示时会自动调整到一行内。

## 🔧 关键代码

### HTML 结构
```html
<div class="row" style="margin: 0;">
    <!-- 10个下拉框，每个包裹在栅格列中 -->
</div>
```

### CSS 类
- `form-control` - Bootstrap 表单控件类
- `v_required` - 必填验证类
- `padding: 0 5px 5px 0` - 统一间距
