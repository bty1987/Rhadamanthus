## 📐 布局代码

### HTML 结构
```html
<div class="form-group default">
    <div class="col-sm-12">
        <div style="display: flex; flex-wrap: wrap; gap: 10px; align-items: center;">
            <!-- 第1组 -->
            <select id="input1" class="rule-input v_required" style="width: 150px;"></select>
            <select id="separator1" class="rule-separator" style="width: 120px;"></select>

            <!-- 第2组 -->
            <select id="input2" class="rule-input v_required" style="width: 150px;"></select>
            <select id="separator2" class="rule-separator" style="width: 120px;"></select>

            <!-- ... 其他组 ... -->
        </div>
    </div>
</div>
```

### CSS 属性说明
| 属性 | 值 | 说明 |
|------|-----|------|
| `display` | `flex` | 弹性盒子布局 |
| `flex-wrap` | `wrap` | 允许换行 |
| `gap` | `10px` | 项目之间间距 |
| `align-items` | `center` | 垂直居中对齐 |
| `width` (输入) | `150px` | 输入框宽度 |
| `width` (连接符) | `120px` | 连接符框宽度 |

## 🎯 用户体验

### 优势
1. ✅ **一目了然** - 整个规则结构清晰可见
2. ✅ **节省空间** - 不需要5行的垂直空间
3. ✅ **操作便捷** - 从左到右依次选择，符合阅读习惯
4. ✅ **灵活适配** - 自动适应不同屏幕尺寸

### 使用流程
```
1. 用户看到整行下拉框
2. 从左到右依次选择
   输入1 → 连接符1 → 输入2 → 连接符2 → ...
3. 实时看到下方生成的正则表达式和示例
4. 确认无误后点击保存
```
