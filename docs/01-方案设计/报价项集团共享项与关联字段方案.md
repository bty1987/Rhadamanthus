> 编制日期:2026-10-06(v2.1,四条拍板已并入;v1「集团报价版本承载」方向废弃)
> 范围:`quotation.quotationCtem`/`quotation.quotationformat`/`data.cormrice` 三表、QuotationFormat/Cormrice 及新增 Cormtime/Cormood 的 Action/Service/DAO/PO/VO(`src/com/fanglin/data/`)、`quotationItem` 加关联列、老版页面 `WebContent/views/quotation/{quotationCtem,quotationFormat,quotationItem}.html` + 同名 js、`WebContent/views/data/cormrice.html` + 新增 cormtime/cormood 页;**app 无共享项/规格/报价项管理页(零 app 改动)**
> 状态:**方案稿,拍板已定,待实施**
> 模型对齐:工程节点 pcnid 先例(763cf219c)——关联仅归集,无快照、无同步、全字段自由,后端零校验,创建必选由前端承载

## 0. 拍板记录(2026-10-06,已并入下文)

1. **三定额挂 qfid(规格级)**,不挂 qcid——工费(cormrice)随之迁移挂点,工时/材料新表直接挂 qfid;
2. **ctem 与 format 不需要 company,本身就是集团数据**——共享项体系全家族无 company 语义(cormrice 存量 company 列保留不删、新行落 0,新两表不设 company);
3. **报价项关联 ctem+format、预填写且不可改——本次不做**,仅预留关联字段,后续再调整创建/编辑逻辑(ctem 关联已存在:quotationItem.quotationCtemId;本次新增 format 关联 qfid 并打通落库链路);
4. **存量回填不考虑**(报价项存量 qfid 不回填;三定额由集团在规格级重新维护)。

v2.1 与 v1 的分界:v1 把共享项落成「集团报价版本(company=0)下的全字段 quotationItem 行」,把报价项当主角——**废弃**。共享项体系本就存在且独立于版本体系,报价项只是消费者。

## 1. 现状(已核实)

### 1.1 共享项体系三表

| `quotation.quotationCtem` | QuotationCtemPO | qcid/name/pinyin/status/type/quotationTypeId/quotationClassificationId/quotationBigCategoryId/quotationSmallCategoryId/measurementUnitId/workTypeId | 共用项主表,全局无 company;四类分类+单位+工种在此 |

### 1.2 报价项消费链路(现状)

- 报价项页名称 typeahead:`quotationItem.js:98` 调 `queryQuotationFormat`(按 quotationFormat.pinyin 搜,分页 0/10),**key 取 qcid、展示 name(ptv 拼接「规格name-format」)**;选中仅留 `quotationItem.qcid`,**具体规格(qfid)被丢弃**(quotationItem.js:554),同共享项多规格时 key 冲突;
- 保存强约束:qcid 为空提示「输入名称不匹配」不允许提交(quotationItem.js:514)——**创建必选规格由前端承载,后端零校验,与工程节点先例同型**;
- `quotationItem` 已有 `quotationCtemId` 列,add/update 均写(QuotationItemServiceImpl.java:173/211);编辑弹窗不回显规格(edit() 未设 qcid,保存传 null——现状,不动);
- 规格 UI 消费点仅此一处;app 侧无页面(app/js/api/data.js 仅 cormrice 接口注册)。

## 2. 方案(三条需求逐一落位)

### 2.1 需求 1「报价项拥有的字段,规格都要有」→ quotationformat 加 13 列

镜像 `quotationItem` 字段,**列名/列型与 quotationItem 同名列对齐**:

| 新列 | 类型(对齐 quotationItem) | 对应报价项字段 |
|---|---|---|
| alias | varchar | alias |
| workType | int FK(对齐本表 unit 列命名风格,nullable) | workTypeId |
| addPrice / subPrice / cost / achePrice | int default 0 | 同名 |
| formula | varchar | formula |
| type | smallint default 0 | type |
| discount | smallint default 0 | discount(0/1 打折标记) |
| isRtem / isImportant | smallint default 0 | 同名 |
| rtemFlag | varchar | rtemFlag |
| comment | varchar | comment |

**边界(不加列的说明)**:`price` 即报价项 `unitPrice` 同义复用;四类分类经 qcid 由共享项带出(规格是子表,不冗余);`no`(编号)/`qvid`(版本)是报价项自身属性,不镜像;`name/format/pinyin/unit/status/qcid` 已有。

DDL:`sqls/data/QUOTATIONFORMAT_MIRROR_ITEM.sql`(幂等 ALTER,风格对齐 CONSTRUCTIONNODE_ADD_PCNID.sql)。

后端几乎零逻辑:PO/VO 加同名字段后,add/update 的 `copyPropertie(s)` 自动透传(QuotationFormatServiceImpl 现排除名单仅 quotationCtem/unit),ptv 自动带出——**接口签名与逻辑零改动**。

### 2.2 需求 2「三个定格数据 工费/工时/材料」→ 三表统一挂 qfid,集团数据无 company

挂载点 = **qfid(规格级)**(拍板 1);共享项体系全家族无 company 语义(拍板 2):

| 定格 | 表 | 处理 | 字段 |
|---|---|---|---|
| 工费 | `data.cormrice` | **迁移**:ALTER 加 `qfid` 列(int not null default 0)+ idx_qfid;维护口径 qcid→qfid | cpid/qcid(保留)/qfid/cnid/unit/trannum/salary/status/company(保留,新行落 0) |
| 工时 | `data.cormtime` | 新建 | ctid/**qfid(FK quotationformat)**/cnid/unit/trannum/workdays decimal(10,2)/status,**无 company**,idx_qfid |
| 材料 | `data.cormood` | 新建 | cgid/**qfid(FK)**/name/**nid(FK noods)**/normunit/normnum/storeunit/storenum/price/status,**无 company**,idx_qfid |

DDL:`sqls/data/CORMRICE_MIGRATE_QFID.sql` + `sqls/data/CORMTIME_CORMOOD_CREATE.sql`(均幂等)。

后端:

- **cormrice**:CormricePO/VO 加 qfid;新增 `queryCormriceByQfid`;`addCormrice` 改落 qfid(VO 带)且不再收 queryCompany(company 固定 0);旧 `queryCormriceByQcid`/`pageCormrice` 保留不删(零破坏,前端不再用);
- **cormtime/cormood**:各一套五件套(PO/VO/Dao/DaoImpl/Service/ServiceImpl/Action,与 cormrice 同包同构),接口按命名规范:`pageCormtime`/`queryCormtimeByQfid`/`addCormtime`/`deleteCormtime`,`pageCormood`/`queryCormoodByQfid`/`addCormood`/`deleteCormood`;add 不落 company;删除重建模式,无 update(对齐 cormrice);
- api 注册对齐 cormrice 现位置(`WebContent/js/api/data.js`)。

前端:

- **规格页(quotationFormat.html/js)承接三定额**:每行加「定额工费/定额工时/定额材料」三按钮,**页面内 modal 弹窗维护**(规格页本身是 popup 弹窗页,不再 popup4page 套整页弹窗;modal 内=定额列表+添加表单,保存后刷新列表、行删除即删);
- **整页保留复用**:`views/data/cormrice.html`(口径已切 qfid)+ 新增 `cormtime.html`/`cormood.html`(照抄 cormrice 页模式),供数据菜单或后续独立入口复用;
- **共用项页(quotationCtem.js)「工费」按钮移除**(挂点迁规格级,行为变化点:工费定额维护入口从共享项迁到规格);
- cormrice 存量行 qfid=0,不做回填(拍板 4);如实施时业务想省重录,可加可选段「仅唯一启用规格的共享项自动回填 qfid」,默认不执行;
- 注记:删除规格(deleteQuotationFormat)为直接删除(对齐现状交互),孤儿定额行由运维 SQL 清理。

### 2.3 需求 3「报价项增加关联共享项/规格的字段」→ quotationItem 加 qfid(预留)

拍板 3:完整形态 = 报价项创建时关联 ctem+format、按规格预填且不可改——**后续调整创建/编辑逻辑时做**;本次仅预留字段并打通落库链路,让关联随现有创建流程开始积累:

- qcid **已存在**(add/update 均写),不重复加;
- 新加列 **`qfid` INT(11) NOT NULL DEFAULT 0**(列名风格对齐本表 qiid/qvid;语义对齐 pcnid:**0=自治/未关联,>0=关联的规格 qfid**)+ 索引 idx_qfid;
- DDL:`sqls/data/QUOTATIONITEM_ADD_QFID.sql`(幂等)。

后端(最小化,零校验零错误码):

| # | 文件 | 改动 |
|---|---|---|
| 1 | QuotationItemPO/VO | 加 `qfid`(int);ptv copyProperties 自动带出 |
| 2 | addQuotationItem | 仅一行 `setQfid(VO 值, null 兜底 0)` |
| 3 | updateQuotationItem | **排除 qfid**(copyProperties 排除名单加 "qfid";关联建行即定,换绑走 SQL,对齐 pcnid 拍板) |

前端(仅落库链路,预填/锁定交互后续做):

- typeahead key **qcid → qfid**(顺带修复同共享项多规格 key 冲突);
- 保存 option 增 `"quotationItem.qfid"`(qcid 照旧);
- 编辑弹窗零改动;app 零改动。

### 2.4 消费方零影响核查

- `quotationformat` 加列:消费点仅报价项 typeahead + 规格页自身,ptv 纯增量;
- `quotationItem` 加 qfid:全报价流程(报价页/增减项/选材/复量)按 qiid 主键直读不动,ptv JSON 多一字段纯增量;
- `cormrice` 迁移:无下游消费者;老接口保留,唯一行为变化=维护入口位置(共用项页→规格页)与口径(qcid→qfid);
- `cormtime`/`cormood` 新表:无既有消费方;版本体系/定额页/选材公式量等近期改动零交叉。
