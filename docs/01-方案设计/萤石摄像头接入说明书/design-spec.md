# Design Spec

本次设计产出是一份从《萤石摄像头接入完整方案.md》提炼出来的 A4 说明文档 HTML，并在选定视觉方向后导出 PDF。目标受众包含业务负责人、施工管理负责人、产品/研发负责人，以及后续可能参与评审的实施人员。文档不需要像网页营销页那样强调宣传性，而应呈现为一份可打印、可归档、可讨论的项目接入说明书。

核心信息必须围绕“为什么摄像头接入不是简单上传图片，而是工地视频资源服务”展开。需要保留几个关键判断：后台负责设备绑定、抓图、存储、授权和素材组织；前台负责图片集播放体验；真实 MP4 视频只在竣工交付、外部分享、宣传案例、争议证据等重场景按需生成。文档应重点讲清：接入目标、系统可复用落点、萤石开放平台调用链路、目标架构、数据模型摘要、后端接口摘要、抓图触发策略、图片集播放策略、权限隐私控制、分阶段实施计划和验收标准。

输出格式为 A4 竖版页面，适合浏览器打印和 PDF 阅读。单页尺寸采用 210mm x 297mm，打印边距由 HTML 自行控制。最终完整版本应控制篇幅，建议 6-8 页 A4，不把原始 1321 行 Markdown 全量搬进去。SQL 细节可以压缩成字段摘要，接口列表可以表格化。视觉气质应专业、克制、清晰、可信，不使用营销式大 hero，不使用紫蓝渐变，不使用大量装饰性图标，不堆无意义数据。

三版视觉方向共同使用真实内容，不引入虚构业务数据。方向一偏正式项目说明书，适合管理层和立项评审；方向二偏技术架构蓝图，强调系统边界、接口链路、模块关系；方向三偏客户体验路线图，强调“直播 + 图片集播放 + 按需视频”的产品价值。三版都只做一页代表页，用于确认排版语言。选定后再扩展为完整 HTML 和 PDF。

内容独有的视觉母题是“从现场摄像头到客户可见内容的链路”。因此版面中应出现清晰的流程结构、能力分层或阶段路线，而不是普通说明书模板。读者第一眼应能抓到结论：先轻量接入，图片集播放优先，视频生成后置。
