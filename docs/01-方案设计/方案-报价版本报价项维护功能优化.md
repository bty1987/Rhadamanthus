# 报价版本/报价项 维护功能优化方案

> 编写日期：2026-05-10
> 模块：data.quotation（报价基础数据）
> 涉及实体：QuotationVersion、QuotationItem、QuotationCtem、QuotationPrice

---

## 一、背景与目标

当前报价版本（QuotationVersion）和报价项（QuotationItem）依赖手动逐条维护，缺少批量操作和复用能力，导致：

- 新建版本后，报价项需从零逐条添加，效率低
- 每条报价项需手动填写名称、分类、单位、工种等十几个字段
- 各公司报价数据独立维护，无法复用已有成果

本次优化目标：通过 **版本复制**、**模板批量添加**、**跨公司复制** 三个功能，减少重复录入，提升维护效率。

---

## 二、功能说明

### 功能1：版本复制

**现状：** 新建报价版本后，报价项需从零逐条手动添加。

**调整：** 新建版本时，可选择一个已有版本作为模板，一键复制其全部报价项到新版本（含价格数据）。

**交互流程：**
1. 用户点击「复制版本」按钮
2. 弹窗中选择源版本（下拉列表，仅显示当前公司已启用的版本）
3. 填写新版本名称、费率等基本信息
4. 确认后系统自动创建新版本，并将源版本所有已启用的报价项复制到新版本下
5. 复制内容包含：名称、分类、单位、工种、价格（addPrice/unitPrice/subPrice）、公式等
6. 每条复制的报价项自动生成新的编号（no）和 QuotationPrice 记录

### 功能2：从通用模板批量添加报价项

**现状：** 每条报价项都要手动填写名称、分类、单位、工种等十几个字段，通用模板（QuotationCtem）数据未被复用。

**调整：** 在报价项列表页增加「从模板添加」功能，从通用模板中勾选多项，批量生成报价项。

**交互流程：**
1. 用户在报价项列表页点击「从模板添加」按钮
2. 弹窗显示通用模板列表，支持按名称搜索、按分类/工种过滤
3. 用户勾选多个模板项（checkbox多选）
4. 设置统一的默认价格（unitPrice/addPrice/subPrice，可单独修改）
5. 确认后批量生成报价项，自动从模板带入：名称、分类、大类、小类、单位、工种
6. 每条自动生成编号（no）和 QuotationPrice 记录

### 功能3：跨公司复制报价版本

**现状：** 各公司的报价版本和报价项完全独立维护，无法复用其他公司已搭建好的报价数据。

**调整：** 支持将A公司的报价版本及其全部报价项一键复制到B公司，新公司无需从零搭建。

**交互流程：**
1. 用户在版本列表页点击「跨公司复制」按钮
2. 弹窗中选择源公司和源版本（级联下拉）
3. 填写新版本名称、费率等基本信息（可修改，不强制沿用源版本费率）
4. 确认后系统在当前公司下创建新版本，并复制源版本所有已启用的报价项
5. 复制内容与功能1相同（名称、分类、价格、公式等全部复制）
6. 复制的报价项归属当前公司，编号重新生成

## 三、技术实现

### 3.1 后端改动

#### 新增方法清单

| 类 | 新增方法 | 说明 |
|----|----------|------|
| QuotationItemService | `copyQuotationItem(String sourceVersionNo, String targetVersionNo, int company)` | 功能1：同公司版本复制 |
| QuotationItemService | `addQuotationItemByCtems(List<Long> ctemIds, String versionNo, int unitPrice, int addPrice, int subPrice)` | 功能2：从模板批量添加 |
| QuotationItemService | `copyQuotationItemCrossCompany(String sourceVersionNo, String targetVersionNo, int sourceCompany, int targetCompany)` | 功能3：跨公司复制 |
| QuotationItemDao | `queryQuotationItemByVersionNo(String versionNo)` | 查询某版本下所有已启用Item |
| QuotationItemDao | `queryQuotationItemByVersionNoAndCompany(String versionNo, int company)` | 查询某公司某版本下所有已启用Item |

#### 核心实现逻辑

**版本复制（功能1 & 功能3共用逻辑）：**

```
1. 根据sourceVersionNo查询源版本及所有已启用Item
2. 创建/查找目标版本（targetVersionNo）
3. 遍历源Item列表：
   a. 新建QuotationItemPO，复制除qiid/no/qvid/versionId外所有字段
   b. 通过CountingService生成新编号(no)
   c. 设置目标版本的versionId/qvid
   d. 保存Item
   e. 新建QuotationPricePO，复制价格，时间用new Date()
4. 返回复制数量
```

**从模板批量添加（功能2）：**

```
1. 根据ctemIds批量查询QuotationCtemPO列表
2. 验证目标版本存在
3. 遍历Ctem列表：
   a. 新建QuotationItemPO
   b. 从Ctem带入：name, quotationType, quotationClassification, 
      quotationBigCategory, quotationSmallCategory, measurementUnit, workType
   c. 设置传入的价格参数
   d. 通过CountingService生成新编号(no)
   e. 保存Item
   f. 新建QuotationPricePO，时间用new Date()
4. 返回添加数量
```

### 3.2 前端改动

#### 功能1 -- quotationVersion.html / quotationVersion.js

- 新增「复制版本」按钮（与「新增」按钮并列）
- 新增复制弹窗：选择源版本（下拉框）+ 新版本基本信息表单
- 调用 copyQuotationVersion.do 接口

#### 功能2 -- quotationItem.html / quotationItem.js

- 新增「从模板添加」按钮（在操作栏区域）
- 新增模板选择弹窗：
  - 通用模板列表（支持搜索、分类过滤）
  - checkbox多选
  - 统一价格填写（unitPrice/addPrice/subPrice三个输入框）
- 调用 batchAddQuotationItemByCtems.do 接口

#### 功能3 -- quotationVersion.html / quotationVersion.js

- 新增「跨公司复制」按钮
- 新增跨公司复制弹窗：
  - 源公司下拉框（切换后加载该公司的版本列表）
  - 源版本下拉框（级联）
  - 新版本基本信息表单（name/费率等）
- 调用 copyQuotationVersionCrossCompany.do 接口

#### API定义 -- api/quotation.js

新增3个API调用方法：
- `copyQuotationVersion(params, callback)`
- `batchAddQuotationItemByCtems(params, callback)`
- `copyQuotationVersionCrossCompany(params, callback)`
