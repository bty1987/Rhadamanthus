# 前端页面模板样式切换调整计划

> 目标：在现有 `index.html`（多彩 Ace）、`index-metro.html`（暗黑 Metro）、`index-clear.html`（明亮 Clear）三套主框架基础上，启用用户可切换页面模板样式的功能，并保证切换后认证、菜单、首页、业务页面、用户偏好等能力稳定可用。

---

## 1. 背景与现状

当前系统前端主框架存在三套入口：

| 模板 | 入口文件 | 资源目录 | 当前定位 |
| --- | --- | --- | --- |
| 多彩 Ace | `WebContent/index.html` | `assets/ace/` + `css/main.css` | 当前默认主入口 |
| 暗黑 Metro | `WebContent/index-metro.html` | `assets/metro/` + `css/metro.css` | 历史兼容入口 |
| 明亮 Clear | `WebContent/index-clear.html` | `assets/clear/` + `css/clear.css` | 历史兼容入口 |

三套入口并不是单入口动态换肤，而是：

```text
三套独立主框架 HTML + 一套公共业务 JS + 一套约定好的 DOM/选择器协议
```

公共逻辑主要集中在：

- `WebContent/js/index.js`
- `WebContent/js/com/core.js`
- `WebContent/js/com/api.js`
- `WebContent/js/com/load.js`
- `WebContent/js/com/condition.js`
- `WebContent/js/com/searcher.js`
- `WebContent/js/com/validator.js`
- `WebContent/js/com/exporter.js`

三套模板通过保留公共选择器实现兼容，例如：

| 功能 | 公共选择器 |
| --- | --- |
| 菜单容器 | `ul.nav-list` |
| 主内容容器 | `#fl-container` |
| 面包屑 | `.breadcrumb` |
| 当前公司 | `.companyinfo .companyName` |
| 公司下拉 | `#companysel` |
| 用户名 | `.user-name` |
| 用户头像 | `#userImg` |
| 个人资料 | `.userProfile` |
| 修改密码 | `.changePassword` |
| 消息入口 | `.messageList` / `#messageBtn` |
| 版本入口 | `#versionInfo` |
| 帮助入口 | `#faqInfo` |
| 锁屏入口 | `#userLock` |
| 退出入口 | `#logout` |
| 二维码 | `#qrcode` |

## 2. 推荐调整方案

### 2.1 推荐方案：保留三套入口，做刷新式模板切换

用户点击切换模板时：

1. 保存用户选择的模板值：`ace`、`metro`、`clear`。
2. 写入本地存储：`localStorage` / Cookie。
3. 调用用户偏好接口保存到服务端。
4. 跳转到对应入口页面。
5. 新入口复用已有认证 Cookie 重新初始化系统。

模板映射：

| 模板值 | 页面 | 名称 |
| --- | --- | --- |
| `ace` | `index.html` | 多彩 Ace |
| `metro` | `index-metro.html` | 暗黑 Metro |
| `clear` | `index-clear.html` | 明亮 Clear |

### 2.2 暂不推荐：单入口动态 CSS 热切换

不建议短期内改成一个 `index.html` 动态替换 CSS，原因：

1. 三套模板外层 DOM 结构差异明显。
2. 顶部栏、菜单栏、主内容区的布局结构不同。
3. 插件加载列表不一致。
4. 动态热切 CSS 容易出现旧样式残留、插件状态残留、布局错乱。
5. 改动范围大，回归成本高。

因此本阶段采用更稳妥的刷新式切换。

## 3. 成功标准

完成后需要满足：

1. 用户可以在系统页面中切换三种模板：
   - 多彩 Ace
   - 暗黑 Metro
   - 明亮 Clear
2. 切换后刷新进入对应入口页面。
3. 切换后认证状态不丢失。
4. 刷新页面后保持上次模板。
5. 退出重新登录后优先进入上次模板。
6. 服务端用户偏好可同步模板配置。
7. 菜单、首页、业务页面、面包屑、弹窗、搜索器等核心能力在三套模板下可用。
8. 不影响现有默认 Ace 入口。

## 阶段四：实现模板切换逻辑

### 目标

点击模板菜单后，保存选择并跳转到对应入口。

### 任务

在 `WebContent/js/index.js` 中增加公共方法：

1. 获取模板 URL：

```javascript
function getTemplateUrl(template) {
    var templates = config.templates || {};
    var target = templates[template] || templates[config.defaultTemplate || "ace"];

    return target ? target.url : "index.html";
}
```

2. 保存本地模板：

```javascript
function saveTemplateLocal(template) {
    localStorage.setItem("fl_template", template);
    com.setCookie("templateStyle", template, config.timeout);
}
```

3. 保存服务端偏好：

```javascript
function saveTemplateRemote(template) {
    if (!api.personel || !api.personel.updateUserPrefer) return;

    com.post(api.personel.updateUserPrefer, {
        "userPrefer.module": "index",
        "userPrefer.page": "global",
        "userPrefer.pkey": "templateStyle",
        "userPrefer.pvalue": template
    }, null, null, false);
}
```

4. 切换模板：

```javascript
function switchTemplate(template) {
    if (!template || template == window.templateStyle) {
        return false;
    }

    saveTemplateLocal(template);
    saveTemplateRemote(template);

    isF5 = true;
    window.location.href = getTemplateUrl(template) + "?timestamp=" + new Date().getTime();

    return false;
}
```

5. 绑定点击事件：

```javascript
$(".template-switch").on("click", function(e) {
    e.preventDefault();

    var template = $(this).attr("data-template");

    com.confirm("切换模板将刷新页面，当前打开的页面标签会关闭，是否继续？", function() {
        switchTemplate(template);
    });
});
```

6. 当前模板高亮：

```javascript
$(".template-switch").each(function() {
    var $this = $(this);

    if ($this.attr("data-template") == window.templateStyle) {
        $this.addClass("active");
    }
});
```

### 验收标准

- Ace 可以切换到 Metro / Clear。
- Metro 可以切换到 Ace / Clear。
- Clear 可以切换到 Ace / Metro。
- 切换后认证状态不丢失。
- 当前模板菜单项有高亮标识。

## 阶段五：登录后按模板进入系统

### 目标

登录成功后不再固定进入 `index.html`，而是进入用户上次选择的模板。

### 任务

1. 在登录相关 JS 中增加轻量模板 URL 获取函数：

```javascript
function getTemplateIndexUrl() {
    var template = localStorage.getItem("fl_template") || getCookie("templateStyle") || "ace";

    var urls = {
        ace: "index.html",
        metro: "index-metro.html",
        clear: "index-clear.html"
    };

    return urls[template] || "index.html";
}
```

2. 替换登录成功后的固定跳转：

```javascript
window.location.href = getTemplateIndexUrl() + "?timestamp=" + new Date().getTime();
```

3. 检查以下文件中的跳转：

```text
WebContent/js/login.js
WebContent/js/dlogin.js
WebContent/js/xlogin.js
WebContent/js/register.js
WebContent/redirect.html
```

### 验收标准

- 无本地模板记录时，登录默认进入 Ace。
- 本地记录为 `clear` 时，登录进入 Clear。
- 本地记录为 `metro` 时，登录进入 Metro。
- 本地记录异常时，回退到 Ace。

## 阶段六：服务端用户偏好同步

### 目标

用户模板选择可跨浏览器、跨设备恢复。

### 任务

1. 在 `index.js` 中增加读取 `index` 模块用户偏好的逻辑：

```javascript
function loadIndexPrefer() {
    if (!api.personel || !api.personel.queryUserPrefers)
        return false;

    com.post(api.personel.queryUserPrefers, {
        "userPrefer.module": "index"
    }, function(res) {
        $.each(res.userPrefers || [], function(i, v) {
            if (v.page == "global" && v.pkey == "templateStyle") {
                params.templateStyle = v.pvalue;
            }
        });
    }, null, false);
}
```

2. 用户信息加载完成后读取服务端偏好。
3. 偏好优先级建议：

```text
本地最近选择 > 服务端偏好 > 默认 Ace
```

4. 如果本地没有模板记录，且服务端模板与当前模板不同，可以跳转到服务端模板。

### 验收标准

- 用户在 A 设备切换模板后，服务端保存成功。
- 用户在 B 设备首次登录，若本地无模板记录，可进入服务端保存的模板。
- 本地已有模板记录时，本地选择优先。

## 8. 风险与回退方案

### 8.1 风险

1. Clear / Metro 长期未维护，可能存在样式或插件兼容问题。
2. 切换模板会刷新页面，当前打开的标签页会丢失。
3. PC 加密模式需要 `.bin` 文件同步，否则会运行失败。
4. 某些业务页面可能写死 Ace 特有样式，导致在 Clear / Metro 下显示异常。
5. 登录页读取服务端偏好不方便，需要依赖本地存储优先。

### 8.2 回退方案

如果上线后发现 Clear / Metro 问题较多，可快速回退：

1. 隐藏模板切换菜单。
2. 登录跳转恢复默认 `index.html`。
3. 保留已写入的用户偏好数据，不影响业务。
4. Ace 入口不受影响。
