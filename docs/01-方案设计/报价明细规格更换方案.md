## 1. 需求

报价单编辑页（`quotationPart`）可操作报价项行新增「规格」操作：依据 `quotationItem.quotationCtemId`（项目）+ `quotationItem.qfid`（规格）的关联关系，将行上绑定的 qiid 更换为**同版本、同项目、不同规格**的兄弟报价项；工程量/公式/位置保留，单价等随新规格刷新。

## 3. 数据模型

**库存层**（quotation 库）：

```
quotationCtem(qcid, 项目主档)
   └── quotationformat(qfid, 规格: name/format串/价格, 挂 qcid)
quotationItem(qiid) = 版本(quotationVersion.no) × 项目(quotationCtemId) × 规格(qfid)
   → 同版本+同项目天然存在多条不同规格的 qiid（本功能的兄弟集合）
```

**报价单明细层**：`quotationfunctionareaitem`（qfai，按 `qfa.index` 分表）＝ FK `quotationItem` + 冗余 itemName/单位/工种/单价/增补/退减/打折/type。

**选材关联**：`selectionitem`（quoteId=qfaiId + qiid + areaId，type=0）；`preprice`＝报价项 unitPrice **单价**口径（非合计，先例 `AddReduceItemServiceImpl.java:481`）。

## 4. 现状缺口（调研结论）

- `updateQuotationFunctionAreaItem` 更新分支只改 formula/num/initNum（`QuotationFunctionAreaItemServiceImpl.java:117`），**qfai.quotationItemId 建行后无任何换绑通路**——必须新增专用端点。
- 无「按 qiid 圈同版本同项目兄弟集合」的查询端点。
- 库级规格换绑先例：`updateQuotationItemForQfid`（受控 through=0 + 变更记录 TYPE=8 + `sqls/communion/39号`）——本方案照此强度。
- 版本过滤字段口径：`quotationVersion.no`（`queryQuotationItemByIdAVersionId` 同款，`QuotationItemDaoImpl.java:52`）。

## 5. 后端设计

### 5.1 兄弟规格查询 `queryQuotationItemForFormatByQiid`（data 模块，fanglin-data jar）

三层同名（Action / Service / DAO），落 `data.quotation.action.QuotationItemAction`（挨着 `queryQuotationItemByQiid`）。

- **入参**：`quotationItem.qiid`
- **DAO**：`queryQuotationItemForFormatByQiid(long qiid)` —— get 自身取 `(quotationVersion.no, quotationCtemId)`，criteria：`quotationVersion.no` = 自身、`quotationCtemId` = 自身、`status = 0`，按 qfid 排序（含自身，前端置灰）。
- **Service**：自身不存在 → 200013；逐条 ptv 转 VO；`formatName` 组装：qfid>0 取 `quotationFormatDao.get(qfid).getName()`，否则 null（候选个位数规模，循环 get 属明细组装非统计，豁免 count/amount 规则）。
- **返回**：`List<QuotationItemVO>`（qiid/no/name/formatName/单位/工种/unitPrice/addPrice/subPrice/discount/type/qfid）
- **VO**：`QuotationItemVO` 新增 `String formatName`（仅展示用）。
- 查询端点**不登记 operation**（查询放行）；无分页。

### 5.2 明细换规格 `updateQuotationFunctionAreaItemForFormat`（quotation 模块，fanglin-quotation jar）

**签名**：`int updateQuotationFunctionAreaItemForFormat(QuotationVO, QuotationFunctionAreaItemVO)`，`@Transactional(rollbackFor = Exception.class)`，落 `QuotationFunctionAreaItemAction` / Service / DAO 三层。

**入参**：`quotation.qid`、`quotationFunctionAreaItem.quotationFunctionAreaId`（qfaId，分表解析）、`.qfaiId`、`.quotationItemId`（目标）。

**校验链**（顺序执行，全前置校验零 try-catch）：

1. `checkQuotationForStatusByEnabled(qid)` —— 报价单可编辑（现成守卫）。
2. `quotationFunctionAreaDao.get(qfaId)` → `queryQuotationFunctionAreaItemByQfaiId(factoryToClazz(qfaId, index), qfaiId)`；null → **200013**。
3. 当前行未绑定报价项（自定义/车运/管理/税金行）→ **200013**。
4. `oldPO = quotationItemDao.get(当前qiid)`；`targetPO = quotationItemDao.get(目标qiid)`；目标 null 或 status≠0 → **200013**。
5. 幂等：目标 == 当前 qiid → return 0。
6. **同项目**：`targetPO.quotationCtemId == oldPO.quotationCtemId`（任一侧为空按不一致处理）→ 否则 **200073**。
7. **同版本**：`targetPO.quotationVersion.no == quotationPO.quotationVersion.no` → 否则 **200074**。
8. 目标 type ∈ 标准类集合（COMMON/COST/IGNORE/UNACHE/CMPREH，与 create 分支同款清单）→ 否则 **200013** 口径（前端不达此分支，服务端兜底）。
9. **扩展项拦截**（拍板②）：`extensionItemDao.countExtensionItem(qfaId, qfaiId) > 0` → **200043**。
10. **选材拦截**（拍板①）：`selectionItemDao.querySelectionItem(orderId, areaId, qfaiId, TYPE_QUOTATION_SHORT)` 存在且 status ≠ 0 → **200075**。

**更新内容**（formula/num/initNum/index/subtype 一律不动）：

- `currentPO.setQuotationItem(targetPO)`
- 冗余刷新：itemName=targetPO.name、measurementUnit=targetPO.unit.name、workType=targetPO.workType.name、unitPrice、addPrice、subPrice、discount、type=targetPO.type、content=null（标准行置空，create 分支同款）
- `quotationFunctionAreaItemDao.update(currentPO)`

**联动**：

- 初始态选材项（status=0）：`setQiid(目标qiid)` + `setPreprice(targetPO.unitPrice)`（单价口径）+ update。
- **变更记录**：`normChangeRecordDao.save(...)`，`NormChangeRecordPO` 新常量 `TYPE_QUOTATIONFUNCTIONAREAITEM_QIID_INT = 9`（报价明细行换绑报价项/换规格），CHANGETYPE_UPDATE；refId=qfaiId、refNo=新 itemName、before=`规格: {旧qfid} {旧itemName} 单价{旧unitPrice}`、after=`规格: {新qfid} {新itemName} 单价{新unitPrice}`。
- 报价单收尾：`convertQuotationVOToPOForAdvance` + `quotationDao.update`（`updateQuotationFunctionAreaItemForSpec` 同款，刷新 updateTime 进重算口径）。

### 5.3 错误码（error.md 登记，衔接 200070 段）

| 码 | 消息 | 场景 |
|---|---|---|
| 200073 | 报价项与原项目不一致 | 换绑目标不属于同一项目（含任一侧 qcid 为空） |
| 200074 | 报价项版本与报价单版本不一致 | 目标报价项版本 ≠ 报价单版本 |
| 200075 | 报价项已进选材流程,不可更换规格 | 关联选材项 status ≠ 0（拍板①） |

复用：200013 报价项不存在、200043 存在关联扩展项（拍板②）。

### 5.4 价格与关联信息变化联动面（换规格后"什么会变、怎么落"）

| 层 | 变化项 | 处理口径 |
|---|---|---|
| 行级（qfai） | 单价/增补/退减/打折/类型、itemName/单位/工种 | 服务端刷新行（5.2）+ 前端就地重算单元格与价格 attr（6.3） |
| 功能区级 | 区合计显示 | `cacsedeUpdateItem` + `cacsedeUpdateCpItem` + `quo.calculateQuoFeesPost()`（改数量同款） |
| **报价单级** | totalPrice / undisPrice / disPrice / costPrice 等合计 | 前端 `calculateQuoFeesPost()` 实时算入 `quo.basicParams` → **随下一次保存请求**经 `convertQuotationVOToPOForAdvance` 落库（`QuotationServiceImpl:1006-1010`）——与改数量**同款落库时序**，不新造重算端点 |
| 管理费/税金 | TYPE_MANAGE / TYPE_TAX 独立行 | 行单价不随换规格变（非规格行，规格钮不显示）；计税/管理基数随合计重算自然反映 |
| 优惠（quotationPrefer） | 基于提交时快照 | 换规格后重新提交优惠即取新值，与改数量一致，不特殊处理 |
| 选材（selectionitem） | qiid / preprice | 初始态同步（5.2，preprice=新规格单价口径）；非初始态拦截（拍板①）；postprice 初始态不涉及 |
| **价格库（quotationPrice）** | 「更新价格」按 qiid 拉最近调价记录刷行价 | 换绑 qiid 后天然追踪**新规格的价格线**——这是换绑而非改行单价的核心收益，无需额外处理 |
| 增减项（AddReduceItem 带 qiid+quoteItemId 快照） | 引用旧 qiid | **不拦截**：与删行家法对齐（`deleteQuotationFunctionAreaItem:293-298` 仅拦扩展项+选材项，不查增减项）；增减项行价格独立快照，qiid 仅溯源 |
| 状态闸 | 已锁/已删报价单 | `checkQuotationForStatusByEnabled` 兜底；`lockQuotation` 的 200041 未关联选材校验不受初始态同步影响 |
| 变更记录 | before/after | 已带新旧 qfid/名称/单价（5.2） |

## 9. 边界说明

- 只动 quotationPart；auotationPart / extensionPart / addReducePart 等同族页不做（拍板⑤）。
- qfid=0（未关联规格）的报价项：参与兄弟集合（按 qcid 圈定），规格列显示「-」；换绑合法性不受 qfid 影响。
- 候选含自身（前端置灰 + 服务端幂等双保险）。
- 增减项（AddReduce）/ 扩展项（Extension）行不在本方案范围（仅标准报价项行）；其中 AddReduceItem 自带 qiid+quoteItemId 快照、换规格时**不拦截**（与删行家法对齐，见 5.4）。
- **报价单合计落库时序沿用既有家法**：前端 `calculateQuoFeesPost` 实时算入 basicParams，随下一次保存请求经 `convertQuotationVOToPOForAdvance` 落库（改数量同款，页面即时显示、落库滞后一次保存）；若要求换规格后服务端合计即时落库，可在成功回调补发一次 `updateQuotationForAdvance`（页面 157/1529 行已有先例），**默认不加**保持同款。
- 命名均按 METHOD_NAMING_CONVENTION：`query + 对象 + For目的(Format) + By条件(Qiid)`、`update + 对象 + For目的(Format)`（For 在 By 前，先例 `pageSalesForBalanceByCompany`）。
