## 一、现状分析

```

#### 1.5.1 现有加密基础设施

**AESHelper.java** — `src/com/fanglin/core/security/AESHelper.java`（93行）

```java
// encrypt 方法 (行33-47)
public static String encrypt(String content, String key, String ivparam) throws FLException {
    Cipher cipher = Cipher.getInstance("AES/CBC/PKCS5Padding");
    SecretKeySpec skeySpec = new SecretKeySpec(key.getBytes("ASCII"), "AES");
    IvParameterSpec iv = new IvParameterSpec(ivparam.getBytes());
    cipher.init(Cipher.ENCRYPT_MODE, skeySpec, iv);
    byte[] encrypted = cipher.doFinal(content.getBytes("utf-8"));
    return new BASE64Encoder().encode(encrypted);  // ← 使用已弃用的 sun.misc API
}

// decrypt 方法 (行57-75)
public static String decrypt(String content, String key, String ivparam) throws FLException {
    // ... 同算法解密 ...
    byte[] encrypted1 = new BASE64Decoder().decodeBuffer(content);
    byte[] original = cipher.doFinal(encrypted1);
    return new String(original, "utf-8");
}
```

关键特征:
- 算法: `AES/CBC/PKCS5Padding`, 128位密钥（16字节ASCII）
- 编码: `sun.misc.BASE64Encoder/Decoder`（JDK内部API，已标记deprecated）
- 加密输出: 纯 Base64 字符串，无前缀标识，如 `eX3o2SZdrpVOV9HC4UYTRA==`
- 异常: 失败抛 `FLException(110005, "系统处理问题")`
- main 方法(行77-91)中硬编码了**两组密钥**:
  - 默认: `b4d617b336124c63` / `b4d1a58a416957a5`
  - 备用: `844dd1be967b6e9e` / `cdb421d038104126`

## 二、存在的问题

1. **加密范围不足**: phone字段已加密，但 identity(身份证号) 字段明文存储
2. **密钥硬编码**: AES密钥和IV直接写在配置文件中，且固定不变
3. **异常处理不安全**: 加解密失败时原样返回明文，等于没有加密
4. **无密钥轮换机制**: 密钥写死后无法更换，泄露则全量数据暴露
5. **user表未加密**: user.phone / user.identity 均为明文存储

## 四、代码层调整方案

### 第1步: 统一加密工具类

在 `com.fanglin.core.security` 包下新建 `SensitiveDataHelper.java`，替代 FormatUtil 中的加密方法：

```java
// SensitiveDataHelper.java
public class SensitiveDataHelper {

    private static final String ENCRYPT_PREFIX = "ENC(";
    private static final String ENCRYPT_SUFFIX = ")";
    private static final String ENCRYPT_VERSION = "V1"; // 密钥版本号

    // 加密 -- 带版本前缀
    public static String encrypt(String plaintext) {
        if (StringUtils.isEmpty(plaintext)) return plaintext;
        if (isEncrypted(plaintext)) return plaintext; // 已加密不重复加密
        
        try {
            String encrypted = AESHelper.encrypt(
                plaintext,
                KeyManager.getCurrentKey(),
                KeyManager.getCurrentIv()
            );
            return ENCRYPT_PREFIX + ENCRYPT_VERSION + ":" + encrypted + ENCRYPT_SUFFIX;
        } catch (Exception e) {
            throw new RuntimeException("加密失败: " + e.getMessage(), e);
            // 不再静默返回明文!
        }
    }

    // 解密 -- 兼容新旧格式
    public static String decrypt(String ciphertext) {
        if (StringUtils.isEmpty(ciphertext)) return ciphertext;
        
        // 新格式: ENC(V1:xxxx)
        if (isEncrypted(ciphertext)) {
            String inner = ciphertext.substring(
                ENCRYPT_PREFIX.length(), 
                ciphertext.length() - ENCRYPT_SUFFIX.length()
            );
            String version = inner.split(":")[0];
            String data = inner.split(":")[1];
            return AESHelper.decrypt(data, KeyManager.getKey(version), KeyManager.getIv(version));
        }
        
        // 旧格式: 纯Base64密文 (兼容存量数据)
        try {
            return AESHelper.decrypt(
                ciphertext,
                KeyManager.getLegacyKey(),
                KeyManager.getLegacyIv()
            );
        } catch (Exception e) {
            // 兜底: 如果解密失败，可能本身就是明文
            return ciphertext;
        }
    }

    // 判断是否已加密(新格式)
    public static boolean isEncrypted(String value) {
        return value != null 
            && value.startsWith(ENCRYPT_PREFIX) 
            && value.endsWith(ENCRYPT_SUFFIX);
    }
}
```

### 第2步: 密钥管理 -- KeyManager (多级兜底)

```java
// KeyManager.java
package com.fanglin.core.security;

/**
 * 密钥管理器 - 多级兜底设计
 *
 * 密钥获取优先级：
 *   1. JVM启动参数 (-Dfanglin.secret.key=xxx)
 *   2. 环境变量
 *   3. 配置文件 (sysconfig.properties: encryptKeyV1 / encryptIvV1)
 *   4. 默认值 (仅开发环境兜底)
 *
 * 用途：
 *   - 业务数据加密（phone/identity）
 *   - 配置文件加密（properties中的敏感值）
 */
public class KeyManager {

    // ========== 配置优先级常量 ==========
    private static final String SYSTEM_PROP_KEY = "fanglin.secret.key";
    private static final String SYSTEM_PROP_IV = "fanglin.secret.iv";
    private static final String ENV_VAR_KEY = "FANGLIN_SECRET_KEY";
    private static final String ENV_VAR_IV = "FANGLIN_SECRET_IV";

    // ========== 旧密钥（兼容存量数据）==========
    private static final String LEGACY_KEY = "b4d617b336124c63";
    private static final String LEGACY_IV  = "b4d1a58a416957a5";

    // ========== 默认值（开发环境兜底）==========
    private static final String DEFAULT_KEY = "b4d617b336124c63";
    private static final String DEFAULT_IV  = "b4d1a58a416957a5";

    // ========== 缓存 ==========
    private static String cachedKey = null;
    private static String cachedIv = null;
    private static boolean initialized = false;

    /**
     * 获取当前主密钥（多级兜底）
     */
    public static String getCurrentKey() {
        return getKeyInternal("key");
    }

    /**
     * 获取当前IV（多级兜底）
     */
    public static String getCurrentIv() {
        return getKeyInternal("iv");
    }

    /**
     * 内部密钥获取逻辑
     */
    private static synchronized String getKeyInternal(String type) {
        // 已缓存直接返回
        if (initialized) {
            return "key".equals(type) ? cachedKey : cachedIv;
        }

        // 1. JVM启动参数
        String sysProp = System.getProperty(
            "key".equals(type) ? SYSTEM_PROP_KEY : SYSTEM_PROP_IV
        );
        if (!isEmpty(sysProp)) {
            return cacheAndReturn(sysProp);
        }

        // 2. 环境变量
        String envVar = System.getenv(
            "key".equals(type) ? ENV_VAR_KEY : ENV_VAR_IV
        );
        if (!isEmpty(envVar)) {
            return cacheAndReturn(envVar);
        }

        // 3. 配置文件（从SystemConfig读取，必须明文存储）
        String configKey = "key".equals(type) ? "encryptKeyV1" : "encryptIvV1";
        String configValue = SystemConfig.getString(configKey);

        if (!isEmpty(configValue)) {
            // ⚠️ 配置文件中的密钥必须明文存储，不能是 ENC() 格式
            // 否则会形成循环依赖
            return cacheAndReturn(configValue);
        }

        // 4. 默认值（兜底，仅开发环境使用）
        return cacheAndReturn(
            "key".equals(type) ? DEFAULT_KEY : DEFAULT_IV
        );
    }

    /**
     * 缓存密钥（仅初始化时）
     */
    private static String cacheAndReturn(String value) {
        if (cachedKey == null) {
            cachedKey = getKeyInternal("key"); // 重新获取
            cachedIv = getKeyInternal("iv");
            initialized = true;
        }
        return value;
    }

    /**
     * 根据版本号获取密钥（用于多版本共存）
     */
    public static String getKey(String version) {
        switch (version) {
            case "V1": return getCurrentKey();
            default: throw new RuntimeException("未知密钥版本: " + version);
        }
    }

    /**
     * 根据版本号获取IV
     */
    public static String getIv(String version) {
        switch (version) {
            case "V1": return getCurrentIv();
            default: throw new RuntimeException("未知密钥版本: " + version);
        }
    }

    /**
     * 获取旧密钥（兼容存量数据）
     */
    public static String getLegacyKey() {
        return LEGACY_KEY;
    }

    public static String getLegacyIv() {
        return LEGACY_IV;
    }

    /**
     * 判断字符串是否为空
     */
    private static boolean isEmpty(String str) {
        return str == null || str.trim().isEmpty();
    }

    /**
     * 重置缓存（测试用）
     */
    public static void resetCache() {
        cachedKey = null;
        cachedIv = null;
        initialized = false;
    }
}
```

## 五、存量数据迁移方案（影子表 + 分批迁移）

### 5.1 设计思路

```
核心原则: 不动原表，建影子表做中转

数据流:
  原表(明文/旧密文) ──读取──> 脚本解密得到明文 ──新密钥加密──> 写入影子表
  影子表同时存储: 明文原文 + 加密后密文（冗余，用于校验和回退）

优势:
  [1] 原表零风险 — 整个迁移过程原表数据不变
  [2] 可反复执行 — 影子表数据不对，清空重来即可
  [3] 分批低峰执行 — 每分钟处理一批，不影响线上性能
  [4] 冗余可校验 — 明文与密文同存，随时可验证加密正确性
  [5] 最终合并简单 — 一条 UPDATE ... JOIN 即可写回原表
```

```python
#!/usr/bin/env python3
# migrate_sensitive_shadow.py
# 存量敏感数据 → 影子表 分批迁移脚本
#
# 运行方式: crontab 每分钟执行一次，或手动循环执行
#   * * * * * cd /path/to/script && python3 migrate_sensitive_shadow.py >> migrate.log 2>&1
#
# 特性:
#   - 每次执行处理一批 (默认1000条)
#   - 原表只读，不修改任何数据
#   - 影子表同时存储明文和密文
#   - 支持断点续跑，通过 migrate_status 追踪进度
#   - 支持校验模式: 解密密文与明文比对

import pymysql
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad
import base64
import time
import sys
from datetime import datetime

# ========== 数据库配置 ==========
DB_HOST = 'your-db-host'
DB_PORT = 3306
DB_USER = 'migration_user'
DB_PASS = 'your-password'
DB_NAME = 'communion'

# ========== 密钥配置 ==========
# 旧密钥 (用于解密已加密的 phone 字段)
LEGACY_KEY = b'b4d617b336124c63'
LEGACY_IV  = b'b4d1a58a416957a5'

# 新密钥V1 (与 KeyManager.java 中的 encryptKeyV1/encryptIvV1 一致)
NEW_KEY = b'xxxxxxxxxxxxxxxx'  # TODO: 替换为实际新密钥 (16字节)
NEW_IV  = b'xxxxxxxxxxxxxxxx'  # TODO: 替换为实际新IV   (16字节)

# ========== 迁移参数 ==========
BATCH_SIZE = 1000          # 每批处理记录数
ENCRYPT_PREFIX = "ENC(V1:"
ENCRYPT_SUFFIX = ")"

# ========== AES 加解密 ==========

def aes_encrypt(plaintext, key, iv):
    """AES/CBC/PKCS5Padding 加密，返回 Base64 字符串"""
    cipher = AES.new(key, AES.MODE_CBC, iv)
    padded = pad(plaintext.encode('utf-8'), AES.block_size)
    encrypted = cipher.encrypt(padded)
    return base64.b64encode(encrypted).decode('utf-8')

def aes_decrypt(ciphertext_b64, key, iv):
    """AES/CBC/PKCS5Padding 解密，输入 Base64 字符串"""
    raw = base64.b64decode(ciphertext_b64)
    cipher = AES.new(key, AES.MODE_CBC, iv)
    decrypted = unpad(cipher.decrypt(raw), AES.block_size)
    return decrypted.decode('utf-8')

def is_old_encrypted(value):
    """判断是否为旧格式加密数据 (纯 Base64，无 ENC() 前缀)"""
    if not value or len(value) < 10:
        return False
    try:
        decoded = base64.b64decode(value)
        if len(decoded) % AES.block_size != 0:
            return False
        aes_decrypt(value, LEGACY_KEY, LEGACY_IV)
        return True
    except Exception:
        return False

def is_new_encrypted(value):
    """判断是否为新格式加密数据 ENC(V1:xxx)"""
    return value and value.startswith(ENCRYPT_PREFIX) and value.endswith(ENCRYPT_SUFFIX)

def to_plaintext(value):
    """将任意格式的值还原为明文"""
    if not value or len(value.strip()) == 0:
        return ''
    value = value.strip()
    if is_new_encrypted(value):
        # 新格式: 提取版本和密文部分
        inner = value[len(ENCRYPT_PREFIX):-len(ENCRYPT_SUFFIX)]
        parts = inner.split(':', 1)
        return aes_decrypt(parts[1], NEW_KEY, NEW_IV)
    if is_old_encrypted(value):
        # 旧格式: 直接用旧密钥解密
        return aes_decrypt(value, LEGACY_KEY, LEGACY_IV)
    # 明文
    return value

def to_new_encrypted(plaintext):
    """将明文加密为新格式 ENC(V1:xxx)"""
    if not plaintext:
        return ''
    encrypted = aes_encrypt(plaintext, NEW_KEY, NEW_IV)
    return ENCRYPT_PREFIX + encrypted + ENCRYPT_SUFFIX


# ========== 迁移任务定义 ==========

TASKS = [
    {
        'source_table': 'customer',
        'shadow_table': 'customer_shadow',
        'id_col': 'cid',
        'columns': ['phone', 'identity'],
        'extra_select': [],  # 无额外字段
    },
    {
        'source_table': 'customerPhone',
        'shadow_table': 'customerphone_shadow',
        'id_col': 'cpid',
        'columns': ['phone'],
        'extra_select': ['cid'],  # 冗余存储关联 cid
    },
    {
        'source_table': 'user',
        'shadow_table': 'user_shadow',
        'id_col': 'uid',
        'columns': ['phone', 'identity'],
        'extra_select': [],
    },
]


def get_batch_no():
    """生成批次号: YYYYMMDDHHMMSS"""
    return int(datetime.now().strftime('%Y%m%d%H%M%S'))


def migrate_batch(conn, task, batch_no):
    """
    从源表读取一批未迁移的记录，写入影子表。
    返回: (本批处理数, 本批插入数, 本批跳过数, 错误数)
    """
    source = task['source_table']
    shadow = task['shadow_table']
    id_col = task['id_col']
    columns = task['columns']
    extra = task.get('extra_select', [])

    cursor = conn.cursor(pymysql.cursors.DictCursor)

    # 查询源表中尚未在影子表存在 (migrate_status=0) 的记录
    # 使用 LEFT JOIN 排除已迁移的记录
    select_cols = [id_col] + columns + extra
    col_str = ', '.join([f's.{c}' for c in select_cols])

    sql_select = f"""
        SELECT {col_str}
        FROM {source} s
        LEFT JOIN {shadow} sh ON s.{id_col} = sh.{id_col}
        WHERE sh.{id_col} IS NULL
           OR sh.migrate_status = 0
        ORDER BY s.{id_col}
        LIMIT %s
    """
    cursor.execute(sql_select, (BATCH_SIZE,))
    rows = cursor.fetchall()

    if not rows:
        return 0, 0, 0, 0

    processed = 0
    inserted = 0
    skipped = 0
    errors = 0

    for row in rows:
        row_id = row[id_col]
        processed += 1

        # 构建影子表记录
        fields = [id_col]
        values = [row_id]

        # 添加额外冗余字段 (如 cid)
        for ext_col in extra:
            fields.append(ext_col)
            values.append(row.get(ext_col))

        has_data = False  # 至少有一个字段有值才写入

        for col in columns:
            raw_value = row.get(col)
            if not raw_value or len(str(raw_value).strip()) == 0:
                # 空值: 明文和密文都存 NULL
                fields.append(f'{col}_plain')
                values.append(None)
                fields.append(f'{col}_enc')
                values.append(None)
                continue

            raw_str = str(raw_value).strip()
            has_data = True

            # 解密得到明文
            plaintext = to_plaintext(raw_str)
            # 用新密钥加密
            encrypted = to_new_encrypted(plaintext)

            fields.append(f'{col}_plain')
            values.append(plaintext)
            fields.append(f'{col}_enc')
            values.append(encrypted)

        if not has_data:
            skipped += 1
            continue

        # 添加迁移元信息
        fields.extend(['migrate_status', 'migrate_time', 'batch_no'])
        values.extend([1, datetime.now(), batch_no])

        # INSERT ... ON DUPLICATE KEY UPDATE
        placeholders = ', '.join(['%s'] * len(values))
        field_str = ', '.join(fields)
        update_str = ', '.join([f'{f}=VALUES({f})' for f in fields if f != id_col])

        sql_insert = f"""
            INSERT INTO {shadow} ({field_str})
            VALUES ({placeholders})
            ON DUPLICATE KEY UPDATE {update_str}
        """

        try:
            cursor.execute(sql_insert, values)
            inserted += 1
        except Exception as e:
            errors += 1
            print(f"  [ERROR] {shadow}.{id_col}={row_id}: {e}")
            conn.rollback()

    conn.commit()
    return processed, inserted, skipped, errors


def verify_batch(conn, task, sample_size=50):
    """
    校验影子表数据: 随机抽取若干条，解密密文与明文比对。
    返回: (校验通过数, 校验失败数)
    """
    shadow = task['shadow_table']
    id_col = task['id_col']
    columns = task['columns']

    cursor = conn.cursor(pymysql.cursors.DictCursor)

    # 构建查询字段
    select_parts = [id_col]
    for col in columns:
        select_parts.append(f'{col}_plain')
        select_parts.append(f'{col}_enc')
    col_str = ', '.join(select_parts)

    cursor.execute(f"""
        SELECT {col_str} FROM {shadow}
        WHERE migrate_status = 1
        ORDER BY RAND()
        LIMIT %s
    """, (sample_size,))
    rows = cursor.fetchall()

    passed = 0
    failed = 0

    for row in rows:
        row_id = row[id_col]
        all_ok = True

        for col in columns:
            plain = row.get(f'{col}_plain')
            enc = row.get(f'{col}_enc')

            if not plain or not enc:
                continue

            # 解密密文，与明文比对
            try:
                inner = enc[len(ENCRYPT_PREFIX):-len(ENCRYPT_SUFFIX)]
                encrypted_b64 = inner.split(':', 1)[1]
                decrypted = aes_decrypt(encrypted_b64, NEW_KEY, NEW_IV)

                if decrypted != plain:
                    print(f"  [VERIFY FAIL] {shadow}.{id_col}={row_id} col={col}: "
                          f"plain={plain} != decrypted={decrypted}")
                    all_ok = False
            except Exception as e:
                print(f"  [VERIFY ERROR] {shadow}.{id_col}={row_id} col={col}: {e}")
                all_ok = False

        if all_ok:
            passed += 1
            # 校验通过，更新状态为 2
            cursor.execute(
                f"UPDATE {shadow} SET migrate_status=2 WHERE {id_col}=%s",
                (row_id,)
            )
        else:
            failed += 1

    conn.commit()
    return passed, failed


def get_progress(conn, task):
    """查询迁移进度"""
    shadow = task['shadow_table']
    source = task['source_table']
    id_col = task['id_col']

    cursor = conn.cursor(pymysql.cursors.DictCursor)

    cursor.execute(f"SELECT COUNT(*) as cnt FROM {source}")
    total = cursor.fetchone()['cnt']

    cursor.execute(f"SELECT COUNT(*) as cnt FROM {shadow} WHERE migrate_status >= 1")
    migrated = cursor.fetchone()['cnt']

    cursor.execute(f"SELECT COUNT(*) as cnt FROM {shadow} WHERE migrate_status = 2")
    verified = cursor.fetchone()['cnt']

    return total, migrated, verified

                filled = int(bar_len * pct / 100)
                bar = '█' * filled + '░' * (bar_len - filled)
                print(f"  {task['source_table']:20s} [{bar}] {pct:5.1f}%  "
                      f"{migrated}/{total}  校验通过:{verified}")

        else:
            print(f"用法: python3 {sys.argv[0]} [migrate|verify|status]")
            print(f"  migrate  - 执行一批迁移 (默认)")
            print(f"  verify   - 校验已迁移数据")
            print(f"  status   - 查看迁移进度")

    finally:
        conn.close()


if __name__ == '__main__':
    main()
```

## 七、渐进式迁移路线图（向后兼容）

```
核心设计原则:
  ✅ 向后兼容：新旧数据可混存
  ✅ 渐进式：可先部署代码，再逐步加密数据
  ✅ 零停机：迁移过程不影响业务运行
  ✅ 多级兜底：多种密钥来源自动选择

---

### 7.1 密钥配置优先级

```
1. JVM启动参数 (最高优先级)
   -Dfanglin.secret.key=xxxxxxxxxxxxxxxx
   -Dfanglin.secret.iv=xxxxxxxxxxxxxxxx

2. 环境变量 (次优先级)
   export FANGLIN_SECRET_KEY=xxxxxxxxxxxxxxxx
   export FANGLIN_SECRET_IV=xxxxxxxxxxxxxxxx

3. 配置文件 (第三优先级)
   sysconfig.properties:
     encryptKeyV1=xxxxxxxxxxxxxxxx  ← 必须明文存储
     encryptIvV1=xxxxxxxxxxxxxxxx   ← 必须明文存储

4. 硬编码默认值 (兜底，仅开发环境)
   b4d617b336124c63 / b4d1a58a416957a5
```

⚠️ **重要约束**：配置文件中的密钥必须明文存储，不能是 `ENC(xxx)` 格式
否则会形成循环依赖（解密需要密钥，密钥在配置文件中需要解密）

---

### 7.2 数据格式兼容性

| 格式 | 业务数据 | 配置文件 | 处理逻辑 |
|------|---------|---------|---------|
| **明文** | phone="13800138000" | password="mypwd" | 直接使用 |
| **旧密文** | phone="8aKJ3mN9..." | 不推荐 | 用LegacyKey解密 |
| **新密文** | phone="ENC(V1:8aKJ3...)" | password="ENC(TAcma...)" | 用KeyManager解密 |

自动识别：
```
SensitiveDataHelper.decrypt(value):
  if (value以"ENC(V1:"开头且以")"结尾)  → 用KeyManager当前密钥解密
  else if (是Base64格式)                 → 用LegacyKey解密
  else (解密失败)                        → 返回明文（兜底）

EncryptPropertyPlaceholderConfigurer.resolvePlaceholder():
  if (value以"ENC("开头且以")"结尾)      → 用KeyManager当前密钥解密
  else                                   → 直接返回明文
```
